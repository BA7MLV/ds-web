DeepStudent｜AI 原生、本地优先的开源学习系统

DeepStudent 基于 Tauri 2 构建，AGPL-3.0 开源。它以「对话即入口」串起学习资料管理、RAG 检索、题库练习与 Anki 制卡：导入资料，边聊边读，一键制卡，按计划复习。

  • 本地优先：离线可用，数据存在你自己的电脑里，可备份、可加密
  • 入口统一：Chat V2 + Skills + MCP 工具生态 + CardForge 制卡任务
  • 资料统一：VFS 单一数据源，全文检索与向量检索（RAG）
  • 学习闭环：题库练习、错题归档、知识导图、翻译工作台

常见问题

DeepStudent 是云服务吗？

不是。数据默认保存在本地，无需注册登录；第三方模型与搜索服务均为可选配置。

需要自备 API Key 吗？

可选。既支持配置自己的模型 Key，也内置合作伙伴提供的免费模型，下载即可体验。

它和 Anki 的关系是什么？

CardForge 可从文档或对话中提取知识点生成卡片，支持导出 APKG，或经 AnkiConnect 同步到 Anki。
