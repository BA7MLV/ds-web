# 关于 DeepStudent

## 项目定位

**只专注学习本身就够了，剩下的都交给我。**

DeepStudent 是开源、本地优先的 AI 学习工作台（AGPL-3.0），基于 Tauri 2 构建，支持 macOS、Windows、Linux 与 Android。它的学习 Agent 可直接操作学习桌面上的每一个应用：笔记、思维导图、题目集、闪卡与待办都由它直接读写，整理、出题、制卡和复习安排可交给它完成。

## 核心理念

### 1) 能动手
说一句话，Agent 即可打开对应的应用，完成写笔记、建思维导图、出题、制卡、排复习、建待办与调研，结果直接写进应用。

### 2) 可托付
长任务可跨轮自动推进；每一步操作按风险分级审批，笔记与学习桌面上的改动可撤销，回答中的引用可回溯到原文。

### 3) 数据在本机
资料、笔记与聊天记录默认保存在本机；调用模型、外部搜索、MCP 或开启云同步时，相应请求才会发往你配置的服务。源码以 AGPL-3.0 开放，可自行核对。

## 系统组成

- **学习桌面**：各个应用以窗口形式并排摆放，从 Dock 打开；
- **学习 Agent**：对话中的执行者，按需加载技能，经审批后操作各个应用；
- **资源库**：教材、笔记、题目与文档统一入库，并建立 AI 检索索引；
- **学习应用**：对话、笔记、思维导图、题目集、闪卡、作文批改、翻译、待办与番茄钟；
- **技能与 MCP**：56 个内置技能，可安装社区技能，也可接入 MCP 服务；
- **设置与数据治理**：13 家预置模型服务商，备份、同步与审计。
