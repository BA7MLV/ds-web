# 关于 DeepStudent

## 项目定位

**只专注学习本身就够了，剩下的都交给我。**

DeepStudent 是开源、本地优先的 AI 学习工作台（AGPL-3.0），采用 **Electron 45（桌面端）+ Capacitor 8.6（移动端）+ WebUI & PWA + Cordis 4 双内核插件架构**，支持 macOS、Windows、Linux、Android 以及自托管浏览器 / PWA（iOS 可通过 Xcode 自构建）。它的学习 Agent 可直接操作学习桌面上的每一个应用：笔记、思维导图、音视频、题目集、闪卡与待办都由它直接读写，整理、讲解、出题、制卡和复习安排可交给它完成。

## 核心理念

### 1) 能动手
说一句话，学习 Agent 即可打开对应的应用，完成写笔记、建思维导图、整理音视频讲义、出题、制卡、排复习、建待办与调研，结果直接写进应用，还能在对话中生成交互式组件辅助理解。

### 2) 可托付
长任务与 Super 并行子代理会话可跨轮自动推进；每一步操作按风险分级审批，笔记与学习桌面上的改动可撤销，回答中的引用可回溯到原文页码或视频时间戳。

### 3) 数据在本机
资料、笔记、索引与聊天记录默认保存在本机；调用模型、外部搜索、MCP 或开启云同步时，相应请求才会发往你配置的服务。源码以 AGPL-3.0 开放，可自行核对与自托管部署。

## 系统组成

- **学习桌面**：16+1 个学习应用以窗口形式并排摆放，从 Dock 打开并支持分屏平铺；
- **学习 Agent**：对话中的执行者，支持**生成式 UI** 与 **Super 会话**（并行子代理），按需加载技能并经审批后直接操作各个应用；
- **资源库**：教材、笔记、音视频、题目与文档统一入库，建立本地向量检索索引与跨应用引用；
- **学习应用**：对话、笔记、思维导图、文档阅读与翻译、**音视频**、论文搜索、题目集、闪卡、作文批改、待办与番茄钟；
- **技能、MCP 与 AI 插件工坊**：内置 **58 个技能**，可安装社区技能或接入 MCP 服务器，并可通过 **AI 插件工坊**制作、安装与热加载 `.dstuplugin` 扩展；
- **设置与数据治理**：**15 家预置模型供应商**（含 DeepSeek 官方应用 API 与一键 API Key 自动配置）、**Sync V5** 云同步、本地备份与审计。
