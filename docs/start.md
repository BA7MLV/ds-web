# 快速上手

> 从安装到跑通「配好模型 → 导入资料 → 带着资料提问 → 生成导图、卡片或题目」，大约 10 分钟。

## 第 0 步：安装并打开

前往 [官网下载页](https://deepstudent.cn/download)（国内镜像，下载快）或 [GitHub Releases](https://github.com/helixnow/deep-student/releases/latest) 下载安装包：

| 平台 | 安装包 |
|---|---|
| macOS | Apple 芯片（M 系列）与 Intel 各一个 `.dmg` |
| Windows | `.exe` 安装程序 |
| Linux | `.AppImage`、`.deb`、`.rpm` 三选一 |
| Android | `.apk` |

暂时没有 iPhone / iPad 版本。

> **macOS 提示「已损坏，无法打开」？** 应用还没有经过苹果公证，被系统拦了下来，文件本身没有问题。打开「终端」执行下面这行（会要求输入开机密码），再重新打开应用：
>
> ```bash
> sudo xattr -r -d com.apple.quarantine "/Applications/Deep Student.app"
> ```

第一次打开会看到：

1. **用户协议与隐私政策**：阅读后点「我已阅读并同意」。
2. **欢迎引导**：选择界面语言，浏览三项核心能力（学习资料库、AI 对话与解题、制卡与复习）。
3. 点「**去配置 AI 服务**」直接进入模型配置页（推荐）；也可以先点「先随便看看」，之后再去设置里配。

不需要注册账号，所有数据默认保存在本机（具体位置见文末）。

## 先认识一下桌面端界面

桌面端默认使用「**学习桌面**」：

- **底部 Dock**：默认固定了「对话」「资源库」「设置」「待办」四个应用；最右边的「全部应用」里还有闪卡、Anki 制卡、技能管理、番茄钟等。
- **窗口**：每个应用、每份资料都在独立窗口里打开，可以自由摆放，拖到屏幕边缘松手就能平铺，方便边看教材边提问。
- **顶部状态栏**：显示到期闪卡、制卡任务和番茄钟；按 `⌘K`（Windows / Linux 为 `Ctrl+K`）可以搜索应用与命令。

更习惯「左侧导航 + 单个页面」的传统布局？点状态栏最左边的 DeepStudent 图标，选「退出学习桌面」即可；在「设置 → 学习桌面」里随时可以切回来。下面的步骤以学习桌面为准，括号里注明传统布局的入口。完整介绍见 [学习桌面](/user-guide/workbench)。

## 第 1 步：配好模型服务（必做）

Deep Student 本身不内置 AI 模型，要先接入一家模型服务。打开「设置 → 模型服务」（Dock 里的「设置」；传统布局在左侧导航底部）。

**最省事的路线：硅基流动（SiliconFlow）一键分配**

1. 在供应商列表选择 SiliconFlow，点名称旁的「访问官网」注册账号（[注册入口](https://cloud.siliconflow.cn/i/deadXN1B)，邀请链接），在它的「API 密钥」页面新建一把密钥并复制。
2. 回到应用，把密钥粘贴进输入框，点「**保存 API 密钥**」。
3. 点旁边的「**一键分配**」。应用会自动建好对话、制卡、嵌入、重排序、翻译、OCR、语音识别等一整套模型，并完成分配。

**用其他供应商**

应用预置了 DeepSeek、通义千问、智谱AI、字节豆包、MiniMax、月之暗面、OpenAI、Anthropic、Google Gemini、NVIDIA、Xiaomi MiMo 等，流程都一样：注册 → 拿到 API 密钥 → 在对应供应商里粘贴并「保存 API 密钥」。之后打开「设置 → 模型分配」，至少给「**对话模型**」选一个模型。想让 AI 检索你导入的资料，还要配好嵌入模型（在同一页的「嵌入维度管理」里）。

**不想用云端服务？**

可以接本机运行的模型（Ollama、vLLM、llama.cpp 等），不需要 API 密钥：「模型服务」里点「添加供应商」，类型选 Ollama（或通用适配器），填本机接口地址（Ollama 一般是 `http://localhost:11434/v1`），勾选「无需 API Key」，保存后会自动拉取模型列表。

详细说明见 [模型与供应商配置](/user-guide/models)。

## 第 2 步：发出第一条消息

1. 点 Dock 里的「对话」，再点「新建会话」（传统布局：左侧导航的「新会话」）。
2. 在底部输入框输入任意问题，按 `Enter` 发送。
3. AI 正常回复，说明模型配好了。

如果发送按钮是灰的，或者提示「当前会话尚未就绪」，回到「设置 → 模型分配」检查对话模型。

## 第 3 步：导入第一份学习资料

1. 点 Dock 里的「资源库」（传统布局：左侧导航的「学习资源」）。
2. 把一份 PDF 教材直接拖进窗口，或点工具栏的「新建」→「导入资料…」选择文件。
3. 导入后资料会自动排队建索引（识别文字 → 分块 → 向量化）。在左侧「知识库索引」里能看到进度，状态变成「已索引」后，AI 就能检索这份资料了。

详见 [学习资源中心](/user-guide/learning-hub)。

## 第 4 步：带着资料提问

两种方式，任选其一：

**方式 A：边读边问**

1. 在资源库里双击打开刚导入的 PDF。
2. 勾选页面角落的选择框，选中一两页（一次最多 10 页）。选中的页码会以标签形式出现在对话输入框上方。
3. 在对话里输入问题并发送，回答会带页码引用，点引用能跳回原文。

**方式 B：引用资源库**

1. 点对话输入框左侧的「＋」→「添加文件」→「资源库」。
2. 勾选要引用的教材或笔记，再发送问题。

图片、PDF 也可以直接拖进对话窗口当附件提问。详见 [AI 对话与会话管理](/user-guide/chat)。

## 第 5 步：生成第一个学习产物

用一句话让 AI 把资料整理成学习材料：

- **知识导图**：说「帮我生成 ×× 的知识导图」，点回复里的导图卡片就能打开编辑。详见 [知识导图](/user-guide/mindmap)。
- **Anki 卡片**：说「把这份 PDF 的重点做成 Anki 卡片」，逐张检查后「加入卡片库」，到期时在「闪卡」里复习。详见 [Anki 制卡与模板](/user-guide/anki)、[闪卡复习](/user-guide/flashcards)。
- **题目集**：说「根据这份资料出 10 道选择题」，AI 会建好题目集，随后就能开始练习。详见 [题库与练习](/user-guide/question-bank)。

## 第 6 步（建议）：了解权限开关，做一次备份

- **权限三档**：输入框「＋」→「模式」决定 AI 能做多少事。「问一问」只回答、不改任何东西；「想一想」会先列出计划，你确认后才执行；两个都不开就是「做一做」，按执行档位直接调用工具。看到「工具执行确认」卡片时，按需允许或拒绝即可。详见 [AI 对话与会话管理](/user-guide/chat)。
- **备份**：打开「设置 → 数据治理 → 备份」，做一次「完整备份」，并建议开启「自动备份」。详见 [数据管理与云同步](/user-guide/data-sync)。

## 可选：联网搜索

AI 需要查最新信息时会联网搜索。应用自带免费的 Bing RSS 搜索源，不用任何配置就能用；想要更稳定、更准确的结果，可以在「设置 → 外部搜索」换成 Tavily、博查、智谱、Brave、Google CSE、SerpAPI 或自建的 SearXNG，填好密钥后点「测试连接」。详见 [深度调研与智能记忆](/user-guide/research-memory)。

## 可选：同步卡片到 Anki 桌面版

想把卡片同步到 [Anki](https://apps.ankiweb.net/)，需要本机已打开 Anki，并安装 **AnkiConnect** 插件（插件代码 `2055492159`）。不装也没关系：可以导出 `.apkg` 文件手动导入，或者直接用应用内的「闪卡」复习。详见 [Anki 制卡与模板](/user-guide/anki)。

## 你的数据和隐私

**数据保存位置**

| 平台 | 默认位置 |
|---|---|
| macOS | `~/Library/Application Support/com.deepstudent.app/` |
| Windows | `%APPDATA%\com.deepstudent.app\` |
| Linux | `~/.local/share/com.deepstudent.app/` |

**隐私须知**

- 资料、笔记、聊天记录和索引默认只保存在本机，不会上传到 Deep Student 的服务器。
- API 密钥以 AES-256-GCM 加密后保存在本机。
- 使用 AI 功能时，你的提问和引用的资料会发给**你自己配置的**模型服务商，受对方隐私政策约束。用境外服务（如 OpenAI、Anthropic、Google）时，相关内容会传到境外服务器处理。
- AI 记忆可以在「设置 → 记忆」里关闭，关闭后不再提取、检索或使用个人记忆。
- 云同步默认关闭，只有你主动配置 WebDAV / S3 等存储后才会同步。

## 📱 移动端说明

Android 版的上手流程相同，入口有些差别：

- 移动端没有学习桌面。点左上角 **☰** 或从屏幕左边缘右滑打开抽屉，里面是会话列表和应用导航（会话、资源、待办、闪卡、设置等）。
- 「设置」是两级页面：先选分区，再进入具体设置；顶部搜索框可以直接搜设置项。
- 对话输入框「＋」→「添加文件」里多了「拍照」，可以直接拍教材、拍题目。

完整的移动端操作和功能差异见 [移动端指南](/user-guide/mobile)。
