# 首页重设计（仿 workbuddy.cn）

日期：2026-08-30
状态：已确认

## 背景

将 DeepStudent 文档站首页从 VitePress 默认 `layout: home` 改造为类似 workbuddy.cn 的现代产品落地页风格。

## 已确认决策

| 决策点 | 结论 |
|---|---|
| 板块构成 | 完整复刻：Hero → 功能场景区(tabs) → 深色亮点区 → 底部 CTA；去掉定价/登录/合作伙伴 |
| 视觉风格 | 沿用 WorkBuddy 浅色粉/紫/橙柔和渐变 Hero + 白底区块 + 深色亮点区 |
| Hero 产品图 | 纯 HTML/CSS 模拟界面（假 sidebar + 对话区），透视倾斜 |
| Hero 文案 | 沿用现有 slogan「AI 原生、本地优先的开源学习系统」改写 |
| 技术路线 | 自定义 Vue 页面组件（HomePage.vue）挂载到主题 |

## 页面结构

```
Hero（柔和渐变背景 + 左文案/右模拟界面）
→ 功能场景区（tabs 切换：资料问答 / 笔记导图 / 刷题练习 / 翻译批改）
→ 深色亮点区（本地优先 + 开源免费）
→ 底部 CTA（下载 + GitHub）
→ 页脚沿用 VitePress 默认
```

## Hero 区

- 背景：浅色柔和渐变，粉(#fdf2f8) → 紫(#f5f3ff) → 橙(#fff7ed) 对角过渡；暗色模式换极淡暗色渐变
- 左侧文案：
  - 小徽标行：`开源免费` 胶囊标签
  - 大标题：「AI 原生、本地优先的」+ 第二行高亮「开源学习系统」（品牌深色下划线/色块，不用渐变文字）
  - 打字机轮换副标题：「我帮你 ____」轮换「读文献」「整理笔记」「出考题」「批改作文」，光标闪烁
  - 描述：「上传资料即可问答、生成知识导图、刷题巩固——数据都在你自己的电脑上。」
  - 按钮：黑色主按钮「免费下载」(圆角 8px，hover 微上浮) + 白色描边次按钮「查看指南」
- 右侧模拟界面：假 sidebar（资料列表）+ 对话区（用户提问气泡 + AI 引用资料回答），`perspective + rotateY` 向右倾斜，柔和投影；暗色模式变深色
- 渐变区底部圆弧/斜切过渡到白色场景区

## 功能场景区（白底，标题「你的学习好帮手」）

- 横向居中胶囊 tabs：资料问答 / 笔记导图 / 刷题练习 / 翻译批改，选中项黑底白字
- 每个 tab 左文右图：小标题 + 两三行说明 + 「了解更多 →」链接；右侧真实截图（复用 docs/public/ 现有 deepstudent-pic-start-*.png，圆角 + 轻投影）
- 切换淡入 150ms ease-out
- 内容映射：
  - 资料问答 → RAG 问答截图 → core/core-rag
  - 笔记导图 → 知识导图截图 → core/core-mind
  - 刷题练习 → 刷题界面截图 → core/core-quiz
  - 翻译批改 → 翻译/作文截图 → core/core-trans-write

## 深色亮点区（#111827 背景，圆角大卡片容器）

- 标题：「本地优先，开源免费」（白色）
- 三个横向亮点，简洁线性 SVG 图标：
  - 数据不出本机——所有资料和处理都在本地，断网可用
  - 完全开源——代码公开在 GitHub，可审计、可自建
  - 永久免费——无订阅、无内购、无功能墙
- 静态网格，不做轨道环绕动画

## 底部 CTA

- 延续 Hero 柔和渐变背景，居中排版
- 大标题：「开始你的 AI 学习之旅」
- 按钮组同 Hero：黑色主按钮「免费下载」+ 次按钮「GitHub 仓库」（新窗口）
- 小字：「免费开源 · 支持 Windows / macOS」
- 下载链接到现有下载页路由

## 暗色模式适配

- Hero / CTA 渐变换极淡暗色（dark: 前缀）
- 模拟界面窗口变深色
- 深色亮点区在暗色模式改 #1f2937，避免与页面底色融合
- 功能场景区截图加深色边框

## 文件改动

| 文件 | 改动 |
|---|---|
| docs/.vitepress/theme/components/HomePage.vue | 新建，首页全部区块，Tailwind 样式 |
| docs/.vitepress/theme/index.js | 注册 HomePage 组件 |
| docs/index.md | 精简 frontmatter，正文挂载 `<HomePage />` |
| docs/.vitepress/theme/custom.css | 仅补充无法内联的样式（打字机光标 keyframes 等） |

## 验证

`npm run dev` 自查 → `npm run build` 无警告 → `npm run preview` 终检 + 移动端/暗色模式检查。
