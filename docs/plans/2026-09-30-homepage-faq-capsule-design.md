# 首页 FAQ：发丝线折叠换胶囊折叠

日期：2026-09-30

「DeepStudent 收费吗？／数据会上传到云端吗？／我的数据保存在哪里？／支持哪些平台？／
macOS 提示『已损坏，无法打开』怎么办？这一块能不能用胶囊状的 UI 和 UX。」

指的是首页 `#faq`（`HomePage.vue` 第 ⑥ 块）。开头的五问就是它现有的五条，不是新增内容 ——
这次只换皮，`home.faq.items` 的问答文本一字未动。

## 结论：只换形状，不加颜色，也不加筛选

`.lp-faq`（发丝线分隔的折叠行）保留给下载页，首页改用新的 `.lp-cap`。

**分类不给颜色。** 原型阶段试过给四类各配一个色点（琥珀 / 青 / 蓝 / 紫），结论是不行：
整站只有一套灰阶，`--lp-accent` 亮色 `#1d1d1f`、暗色 `#f5f5f7`，连功能区的轮播圆点
都只是 `rgba(0,0,0,0.16)`。四个分类色点会是页面上**唯一的饱和像素**，
比它要表达的信息还抢眼，而且这套色在暗色下没有对应的一套，等于凭空引进一套新的配色义务。

色点去掉后，分类只剩「一排筛选胶囊」这一种表达方式；**这一排后来也去掉了**
（原型评审时确认）。理由：话题总共五条，筛选行要占的位置和它省下的滚动差不多，
而在默认的「全部」状态下它什么也不做 —— 一个占了区块顶部、多数时候点不出效果的控件。
配套的 `filters` 列表、条目的 `tag` 字段与那组 `aria-pressed` 按钮已一并删除，
不留没有消费者的数据。

## 设计

### 收起态是真胶囊，展开态必须让位

| | 收起 | 展开 |
|---|---|---|
| 行高 | ≈ 46px（`0.85rem` 上下内边距 + 一行 1.5 行高） | 由答案撑到几十上百像素 |
| 圆角 | 24px | 18px |

24px 落在 46px 高的行上，被浏览器钳到半高 23px，两端正好是半圆 —— 这就是胶囊。
展开后同一行变成 120px 高的块，若圆角仍是 24px 就不再是半圆，而成了一道会切到
答案文字的弧。所以展开时退到 18px：两级只差 6px，够看出「胶囊松开了」，
又不至于塌成方块。

`transition` 挂在 `.lp-cap__item` 上而不是按钮上 —— 圆角是容器自己的属性，
按钮只有 46px 高、看不见这个变化。

### 条目恒定是信息容器，不与任何操作抢面

五条并排全是 `--lp-tile` 浅面，不描边不投影，区分靠与页面的底色差
（口径沿用 `--fc-face` 那段）。这一块里没有第二种面 —— 去掉筛选行之后，
唯一的实心反色块只剩顶栏，胶囊之间不必再靠填充差分层级。

## 落地

- `docs/.vitepress/theme/custom.css`：新增 `.lp-cap` 块（紧跟 `.lp-faq` 之后），
  另在 `max-width: 900px`、`max-width: 520px` 与 `prefers-reduced-motion` 三处各补一条。
- `docs/.vitepress/theme/components/HomePage.vue`：第 ⑥ 块换结构，脚本只留
  `openFaq` / `toggleFaq`。
- i18n 消息表**未改动**：`home.faq.items` 的问答文本原样复用，
  加过又删掉的 `filters` / `tag` 没有残留（`tests/i18n-messages.test.mjs` 会兜住漏改）。
- 下载页的 `DownloadFaq.vue` 仍走 `.lp-faq`，本次不动。

## 自检

- 亮 / 暗两套下收起态是不是胶囊（两端半圆）、展开后答案会不会被圆角切到。
- 五条逐一点开再收起，不应出现两条同时展开。
- 520px 以下：圆角收一档、正文左右内边距收一档。
- 系统开「减弱动态效果」后圆角与展开不应再有过渡。
