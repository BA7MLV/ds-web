# 常见问题（FAQ）

## 安装与更新

### macOS 提示「已损坏，无法打开」怎么办？

这是 macOS 对未从 App Store 下载应用的隔离机制，在终端执行以下命令即可：

```bash
sudo xattr -r -d com.apple.quarantine /Applications/DeepStudent.app
```

如果你的安装路径不是 `/Applications/DeepStudent.app`，请替换成真实路径。

### 应用如何更新？

- **桌面端**（macOS / Windows / Linux）：启动后会自动静默检查更新，也可在
  **设置 → 关于** 点击「检查更新」。可选择每次启动检查、每 N 天检查或从不检查。
- **Android**：不走应用内更新，请通过下载渠道获取新版 APK 安装。
- **iOS**：无官方安装包，需自行使用 Xcode 构建。

### 第一次安装后优先做什么？

1. 在 **设置 → 模型服务** 填写一家供应商的 API 密钥（详见 [快速上手](start.md)）。
2. 在 **设置 → 模型分配** 确认对话模型与嵌入模型已配置。
3. 在「学习资源」导入一份资料，回到「新会话」引用它做一次问答。

## 模型与连接

### 测试 API 连接失败怎么办？

按顺序排查：

1. API 密钥是否复制完整、没有多余空格。
2. 接口地址是否正确（自定义供应商注意 `/v1` 后缀）。
3. 当前网络能否访问该服务（部分服务需要特定网络环境）。
4. 供应商账户余额是否充足、密钥是否被禁用。

### 为什么提示「请先配置对话模型」？

对话依赖「对话模型」分配。前往 **设置 → 模型分配**，为「对话模型」选择一个
已启用且供应商已配密钥的模型。

### 为什么 AI 检索不到我导入的资料？

资料问答（RAG）需要**嵌入模型**。请确认：

1. **设置 → 模型分配 → 嵌入模型** 已配置（如 SiliconFlow 的 `BAAI/bge-m3`）。
2. 资源在学习资源列表中显示「已索引」；显示「失败」时可手动重试。
3. 对话中已开启 RAG（`Cmd/Ctrl + Shift + R`）或引用了对应资源。

### 扫描版 PDF 无法提问 / 无法选中文字？

扫描版 PDF 需要先做 OCR 文字识别。请在 **设置 → 模型分配 → OCR引擎** 配置
OCR 模型（SiliconFlow「一键分配」会自动配好），然后重新导入或重试索引。
识别效果不佳时，可在设置中切换更强的 OCR 引擎。

## 制卡与 Anki

### 为什么对话中无法制卡？

制卡工具通过技能按需加载。请先点击输入栏的技能按钮（闪电图标），
激活「**ChatAnki**」技能后再发出制卡指令。

### 制卡失败或卡住了怎么办？

1. 打开侧边栏「**制卡任务**」查看任务状态与错误原因，失败分段可点击**重试**。
2. 确认 **设置 → 模型分配 → Anki制卡模型**（或对话模型）可用且余额充足。
3. 材料过长时可分批制卡，或先让 AI「预估这份材料适合做多少张卡片」。

### 卡片无法同步到 Anki？

一键同步需要：本机已安装并**打开** Anki 桌面端，且安装了 **AnkiConnect** 插件
（代码 `2055492159`）。可在「制卡任务」页的 AnkiConnect 设置中检查连接状态。
无法满足时，改用「导出 APKG」手动导入 Anki。

## 数据与隐私

### 数据会上传到云端吗？

不会。DeepStudent 本地优先，资料、笔记、聊天记录默认只保存在本机。
只有两种情况数据会离开你的设备：① 使用 AI 时，相关内容发送给**你自己配置的**
模型服务商；② 你主动配置了 WebDAV / S3 云同步。

### 我的数据保存在哪里？

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/com.deepstudent.app/` |
| Windows | `%APPDATA%\com.deepstudent.app\` |
| Linux | `~/.local/share/com.deepstudent.app/` |

建议通过 **设置 → 数据治理** 定期导出备份，而不是手动拷贝该目录。

### 云同步提示冲突怎么办？

多端同时修改同一数据时会出现冲突，属正常现象。点击「解决冲突」后通常选
「**保留最新**」即可；确定某台设备的修改更重要时，选「保留本地」或「使用云端」。
详见 [备份与同步](user-guide/05-data-management.md)。

### 如何关闭 AI 记忆？

**设置 → 常规 → 记忆**，关闭开关即可。关闭后 AI 不再提取、检索或注入个人记忆。
已有记忆条目可在 **学习资源 → 记忆管理** 中删除。

## 其他

### 为什么有些功能提示「实验性」？

云同步、多模型并行等功能仍在打磨中，可能存在不稳定情况。使用实验性功能前
建议先做一次完整备份。

### 找不到旧版的「错题本」/「批量制卡」页面？

- 旧版「错题本」已升级为「**题目集**」，数据会在启动时自动迁移。
- 表单式批量制卡已由对话制卡（ChatAnki）替代，进度在「制卡任务」页查看。
