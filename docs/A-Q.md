# 常见问题（FAQ）

这里汇总 DeepStudent 的安装更新、版本迁移、插件故障恢复、AI 模型配置、资料检索、Anki 制卡和数据隐私问题。
首次使用请先阅读[快速上手](start.md)；仍无法解决的问题可通过[支持页面](support.md)反馈。

## 安装、升级与故障恢复

### macOS 提示「已损坏，无法打开」怎么办？

正式发布包已通过 Apple 签名与公证；如果你下载的是未公证的预览版或自构建包，这是 macOS 对未公证应用的隔离机制，在终端执行以下命令即可：

```bash
sudo xattr -r -d com.apple.quarantine "/Applications/Deep Student.app"
```

应用名中间有空格，路径两边的引号不能省。如果你没装在 `/Applications/Deep Student.app`，请把引号里的路径换成真实路径。

### 应用如何更新？

- **桌面端**（macOS / Windows / Linux）：启动后会自动静默检查更新，也可在 **设置 → 关于** 点击「检查更新」，支持选择每次启动检查、每 N 天检查或从不检查。其中 **Linux 仅 `.AppImage` 支持应用内原地更新**（`.deb` 需手动下载新版安装）。桌面端在下载并应用更新前，会自动预检已启用用户插件的兼容性，避免升级后发生冲突。
- **Android**：支持在应用内探测新版本并调起系统安装器完成更新，也可直接通过下载页或 GitHub Releases 获取新版 APK。
- **iOS**：无官方安装包，需自行使用 Xcode + Capacitor 构建。
- **WebUI / PWA**：拉取最新代码并重启本地自托管服务即可（详见 [WebUI 与 PWA 自托管](/user-guide/webui-pwa)）。

### 从 `0.11.x` 升级到 `0.20.x` 数据会丢吗？

不会。`0.20.x` 会**原地挂载**原有的业务数据目录，直接兼容既有 SQLite 数据库与 LanceDB 向量索引；首次启动时自动迁移旧版 `localStorage` 配置，并保留已安装的用户插件。跨大版本升级前，仍建议先在 **设置 → 数据治理** 做一次完整备份，以防意外。

### 如何在浏览器或手机主屏幕以 WebUI / PWA 方式使用？

在一台装有 Node.js 24+ 的电脑或服务器上启动 DeepStudent Web 服务后，即可通过局域网或反向代理在任意现代浏览器打开，并支持「添加到主屏幕」以 PWA 应用形态使用。部署步骤、鉴权配置与反向代理参考 [WebUI 与 PWA 自托管](/user-guide/webui-pwa)。

### 第一次安装后优先做什么？

1. 首次启动欢迎弹窗支持「**一键 API Key 自动配置**」；也可以随时在 **设置 → 模型服务** 手动填写一家供应商的 API 密钥（详见 [快速上手](start.md)）。
2. 在 **设置 → 模型分配** 确认对话模型与嵌入模型已配置。
3. 在「**资源库**」导入一份资料，回到「**对话**」引用它做一次完整问答。

## 模型与连接

### 测试 API 连接失败怎么办？

按顺序排查：

1. API 密钥是否复制完整、没有多余空格。
2. 接口地址是否正确（自定义供应商注意 `/v1` 后缀）。
3. 当前网络能否访问该服务（部分服务需要特定网络环境）。
4. 供应商账户余额是否充足、密钥是否被禁用。

### 为什么提示「请先配置对话模型」？

对话依赖「对话模型」分配。前往 **设置 → 模型分配**，为「对话模型」选择一个已启用且供应商已配密钥的模型。

### 为什么 AI 检索不到我导入的资料？

资料问答（RAG）需要**嵌入模型**。请确认：

1. **设置 → 模型分配 → 嵌入模型** 已配置（如 SiliconFlow 的 `BAAI/bge-m3`）。
2. 资源在**资源库**列表中显示「已索引」；显示「失败」时可手动重试。
3. 对话中已开启 RAG（`Cmd/Ctrl + Shift + R`）或引用了对应资源。

### 扫描版 PDF 无法提问 / 无法选中文字？

扫描版 PDF 需要先做 OCR 文字识别。请在 **设置 → 模型分配 → OCR引擎** 配置 OCR 模型（SiliconFlow「一键分配」会自动配好），然后重新导入或重试索引。识别效果不佳时，可在设置中切换更强的 OCR 引擎。

## 制卡与 Anki

### 为什么对话中无法制卡？

制卡工具通过技能按需加载。请先点击输入栏的技能按钮（闪电图标），激活「**ChatAnki**」技能后再发出制卡指令。

### 制卡失败或卡住了怎么办？

1. 打开「**闪卡 → 制卡**」（Anki 制卡）查看任务状态与错误原因，失败分段可点击**重试**。
2. 确认 **设置 → 模型分配 → Anki制卡模型**（或对话模型）可用且余额充足。
3. 材料过长时可分批制卡，或先让 AI「预估这份材料适合做多少张卡片」。

### 卡片无法同步到 Anki？

一键同步需要：本机已安装并**打开** Anki 桌面端，且安装了 **AnkiConnect** 插件（代码 `2055492159`）。可在「**闪卡 → 制卡**」页面的 AnkiConnect 设置中检查连接状态。无法满足时，改用「导出 APKG」手动导入 Anki。

## 数据与隐私

### 数据会上传到云端吗？

DeepStudent 本地优先，资料、笔记和聊天记录默认保存在本机，但这不等于所有功能都离线。使用 AI 时，请求所需的内容会发送给**你自己配置的**模型服务商；启用外部搜索或 MCP 工具时，相关请求也会发送给对应服务。主动配置 WebDAV / S3 / FTP 云同步后，选定的数据会同步到你配置的存储服务。使用前请确认各服务的数据处理方式。

### 我的数据保存在哪里？

桌面端业务数据目录在三个平台保持为 `com.deepstudent.app`：

| 平台 | 业务数据路径 |
|------|------|
| macOS | `~/Library/Application Support/com.deepstudent.app/` |
| Windows | `%APPDATA%\com.deepstudent.app\` |
| Linux | `~/.local/share/com.deepstudent.app/` |

v0.20 起，Electron 浏览器内核的缓存与会话状态独立存放在同级目录 `com.deepstudent.app.electron` 中，与学习数据隔离。建议通过 **设置 → 数据治理** 定期导出备份，而不是手动拷贝目录。

### 云同步提示冲突怎么办？

多端同时修改同一数据时会出现冲突，属正常现象。点击「解决冲突」后通常选「**保留最新**」即可；确定某台设备的修改更重要时，选「保留本地」或「使用云端」。详见 [数据管理与云同步](/user-guide/data-sync)。

### 如何关闭 AI 记忆？

前往 **设置 → 记忆**，关闭开关即可。关闭后 AI 不再提取、检索或注入个人记忆。已有记忆条目可在 **资源库 → 记忆管理** 中查看或删除。

## 其他

### 为什么有些功能提示「实验性」？

云同步、多模型并行、FSRS-7 桌面试跑等功能仍在持续打磨中，可能存在不稳定情况。使用实验性功能前建议先做一次完整备份。

### 找不到旧版的「错题本」/「批量制卡」页面？

- 旧版「错题本」已升级为「**题目集**」（并内置跨题目集错题本），数据会在启动时自动迁移。
- 表单式批量制卡已由对话制卡（ChatAnki）替代，任务进度与模板统一在「**闪卡 → 制卡**」（Anki 制卡）中查看。
