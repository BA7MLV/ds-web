# 系统设置

## 概述

设置页是 DeepStudent 的配置中心。进入方式：点击侧边栏底部的「**设置**」，
或按 `Cmd/Ctrl + ,`。

设置页采用左侧导航 + 右侧内容的布局，左上角的搜索框可按名称快速定位设置项。
共有 11 个标签页：

| 分组 | 标签页 | 主要内容 |
|------|--------|---------|
| AI 核心 | **模型服务** | 供应商与 API 密钥管理 |
| AI 核心 | **模型分配** | 为对话、嵌入、制卡等场景指派模型 |
| 常规 | **常规** | 语言、语音听写、记忆、系统通知 |
| 常规 | **外观** | 主题色、字体、字号、界面缩放 |
| 扩展 | **MCP工具** | 连接外部工具服务器 |
| 扩展 | **外部搜索** | 配置联网搜索引擎 |
| 数据 | **数据统计** | 学习时长、对话统计、热力图 |
| 数据 | **数据治理** | 备份、恢复、云同步、审计 |
| 高级 | **参数调整** | RAG、OCR、PDF 阅读器等运行参数 |
| 高级 | **快捷键** | 自定义键盘快捷键 |
| 关于 | **关于** | 版本信息、检查更新、隐私政策 |

## 模型服务

模型服务用于管理 AI 供应商及其模型，采用「供应商 → 模型」的层级结构，
同一供应商下的模型共用 API 密钥和接口地址。

### 内置供应商

应用内置 11 家供应商模板，选中后填写 API 密钥即可使用：

SiliconFlow（硅基流动）、DeepSeek、通义千问、智谱AI、字节豆包、MiniMax、
月之暗面、OpenAI、NVIDIA、Xiaomi MiMo、Google Gemini。

内置供应商无法删除。此外可点击供应商列表上方的 **+** 按钮添加自定义供应商，
支持 OpenAI 兼容接口（填写名称与接口地址，如 `https://api.example.com/v1`）。

### 配置 API 密钥

选中供应商后，在右侧面板中：

1. 找到「API 密钥」区域，输入密钥后自动保存。
2. 可点击眼睛图标显示/隐藏密钥，或点击清除按钮移除。
3. 建议随后对任一模型点击「**测试**」，确认连接正常。

### SiliconFlow 一键分配

SiliconFlow 供应商提供一键配置能力，适合新手首配：

1. 选中 SiliconFlow，输入 API 密钥。
2. 点击「**一键分配**」，系统自动创建对话、嵌入、重排序、制卡、翻译、OCR、
   记忆决策等一整套预设模型并完成分配。

| 功能 | 预设模型 |
|------|---------|
| 对话 / 题库 AI 批改 / 题目集解析 | `deepseek-ai/DeepSeek-V3.2` |
| Anki 制卡 | `Qwen/Qwen3-30B-A3B-Instruct-2507` |
| 嵌入（RAG） | `BAAI/bge-m3`（维度 1024） |
| 重排序 | `BAAI/bge-reranker-v2-m3` |
| 标题/标签生成 / 记忆决策 | `inclusionAI/Ling-mini-2.0` |
| 翻译 | `tencent/Hunyuan-MT-7B` |
| OCR（默认） | `PaddlePaddle/PaddleOCR-VL-1.5` |

### 模型管理

选中供应商后在「模型列表」区域点击「添加模型」：

- **显示名称**：模型的友好名称
- **模型标识**：实际调用的模型 ID（如 `gpt-4o`）
- **模型能力**：勾选多模态（图片输入）、推理（思维链）、嵌入、重排序、工具调用等

每个模型卡片支持：启用/禁用开关、星标收藏、编辑、测试连接、删除。
展开编辑面板还可调整 Temperature、最大输出 Token 等高级参数。

## 模型分配

模型分配页为各项功能指派模型。在每个功能卡片中点击下拉选择器，
从已启用的模型中选择，选择后自动保存。

### 必须配置

| 功能 | 说明 |
|------|------|
| **对话模型** | 所有 AI 对话、解题和交互的基础。未配置时无法发送消息 |
| **嵌入模型** | RAG 资料检索必须。需要 embedding 类型的模型 |

### 按需配置（默认回退到对话模型）

| 功能 | 说明 |
|------|------|
| **Anki制卡模型** | 智能生成问答卡片 |
| **标题/标签生成模型** | 生成聊天标题和智能标签 |
| **翻译专用模型** | 翻译工作台 |
| **题库AI批改模型** | 题目集中的 AI 评分与解析 |
| **记忆决策模型** | 记忆写入时的去重判断 |
| **重排序模型** | 对检索结果重排序，提升检索准确性 |
| **OCR引擎** | 题目集识别、扫描 PDF 文字识别 |
| **语音输入 ASR 模型** | 语音听写 |
| **生图模型** | 对话中生成图片 |

### 嵌入维度管理

用于管理 RAG 的向量嵌入配置：点击「创建维度」，输入维度值（如 1024、1536），
选择模态类型并分配嵌入模型，可将某个维度设为默认。

### 配置状态检查

页面底部显示各功能的配置状态（已配置 / 可选未配置 / 必选未配置）。
对话模型配置完成后会显示「基础功能配置完成」。

> 若对话模型未配置，对话页会阻止发送并给出直达「模型分配」的引导。

## 常规

- **界面语言**：中文 / English，切换后立即生效。
- **语音听写**：配置按住说话快捷键（默认 `Cmd/Ctrl + Shift + Space`）、听写词典与历史。
  需要在模型分配中配置 ASR 模型。
- **记忆**：开启/关闭 AI 记忆；选择记忆存储文件夹。详见 [智能记忆](./09-memory.md)。
- **系统通知**：待办提醒、番茄钟完成等通知策略。
- **Anki 连接**：允许通过 AnkiConnect 推送卡片到本机 Anki 的快捷开关。

## 外观

- **主题调色板**：极光蓝（默认）、薰衣紫、森林绿、日落橙、玫瑰粉、青碧色、

- **侧边栏**：位置与显示偏好。

## MCP工具

MCP（Model Context Protocol）用于把外部工具接入 AI 对话。

页面顶部显示连接状态、工具缓存数量与缓存更新时间。

### 添加服务器

- **添加预置**：从预置列表启用（如 **Context7**，免费获取编程库文档，无需密钥）。
- **新增 MCP 工具**：手动填写服务器名称、传输类型（SSE / WebSocket / HTTP / Stdio）、
  地址或命令、命名空间与 API 密钥。支持图形表单或 JSON 两种编辑模式。

> Stdio 类型的 MCP 服务器仅桌面端可用，移动端不支持。

### 日常操作

- 悬停服务器列表项：**预览**、**测试**、**编辑**、**删除**。
- 「快捷操作」菜单：重新连接、刷新清单、体检、清空缓存、安全策略。
- **工具权限管理**：可设置全局免审批，或为单个工具设定敏感等级。

## 外部搜索

配置 AI 对话中的联网搜索能力。在顶部选择默认搜索引擎（仅已配置密钥的引擎可选），
展开各引擎卡片填写密钥，并用「**测试可用性**」验证。

支持的引擎：

| 引擎 | 特点 |
|------|------|
| Google CSE | 覆盖广，需 Google Cloud API Key + CSE ID |
| SerpAPI | 付费，按次计费 |
| Tavily | 为 AI 应用优化，结构化结果 |
| Brave Search | 隐私优先 |
| SearXNG | 可用公共实例或自建，免费方案 |
| 智谱 AI 搜索 | 中文优化，支持意图识别 |
| 博查 AI 搜索 | 中文优化，为 AI 应用设计 |

「高级搜索功能」中还可配置搜索结果重排器、中文可信站点模板、站点黑白名单，
以及注入文本长度上限。

## 数据治理

数据治理负责备份、恢复、云同步、审计和迁移，包含
**概览 / 归档 / 备份 / 同步 / 审计 / 迁移 / 缓存** 七个子页。

常用操作一览：

- **备份**：分层备份（P0 核心数据 ~ P3 大型资产）、完整/增量备份、导出 ZIP。
- **恢复**：从备份列表或 ZIP 文件恢复，恢复前系统自动创建「预恢复备份」。
- **云同步**（实验性）：WebDAV / S3 多端同步与冲突处理。
- **审计**：所有备份/恢复/同步操作的日志。
- **概览**：数据库健康检查。

具体操作步骤请见专页 [备份与同步](./05-data-management.md)。

## 参数调整

配置系统运行参数，日常使用一般无需改动。

- **聊天流式参数**：流式超时时间与自动取消。
- **搜索设置**：语义检索是否使用全文搜索预筛。
- **PDF 阅读器**：渲染分辨率、文本层/批注层范围、缩略图、默认单页/双页视图。
- **OCR 识别**：自动 OCR 总开关、多模态模型跳过 OCR、扫描版 PDF 判定阈值。
- **RAG 与索引维护**、**导师提示词**、**用户偏好** 等。

## 常见问题

**Q：测试 API 连接失败怎么办？**

检查：① API 密钥是否正确；② 接口地址是否正确（注意 `/v1` 后缀）；
③ 网络能否访问该服务；④ 账户余额是否充足。

**Q：配置状态显示「未配置」但我已经选择了模型？**

确认所选模型的开关已打开、所属供应商已填密钥，并点击「测试」验证可用。

**Q：如何使用自定义/代理 API？**

添加新供应商时，在「接口地址」中填写代理地址即可，如 `https://your-proxy.com/v1`。

更多问题见 [常见问题](/A-Q.md)。
