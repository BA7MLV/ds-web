# 文档阅读与翻译

> 内置 PDF / Word / EPUB 阅读器支持双页阅读、高亮批注、书签和「勾选页面问 AI」；选中文字可以解释、翻译、存成笔记、制卡或发到对话；翻译工作台提供全文翻译、逐段双语对照、7 种领域预设与自定义提示词。

<GuideDemo />

## 功能概览

- **PDF 阅读器**：翻页、缩放、旋转、单页/双页视图（含"封面单独成页"）、暗色阅读、侧栏（目录/缩略图/书签/批注）、全文搜索（边扫边出结果）、四色划词高亮、划词翻译，阅读进度与缩放/视图偏好按文档自动记住。
- **划词学习闭环**：选中一段文字，除了高亮，还可以让 AI「解释」「翻译」，「保存为笔记」（带出处，能跳回原文），「制卡」（后台生成记忆卡片），或「添加到聊天」接着问。PDF、Word、PPT、EPUB 都能划词。
- **围绕文档问 AI**：在阅读器里勾选页面，页码会出现在聊天输入栏，输入问题即可让 AI 针对这些页作答；也可以「框选提问」，把公式、图表框出来截图发给 AI；AI 回答中的页码引用可以一键跳回 PDF 对应页。
- **Word / EPUB / 其他格式阅读**：Word 文档以「白纸」版式渲染并可调字号；EPUB 电子书支持目录、护眼主题与排版调节。
- **翻译工作台**：面向精读的翻译工具——全文翻译、段落对照、术语表、领域预设、译文编辑与朗读，翻译记录自动保存为可管理的资源。

适合场景：精读英文教材边读边高亮；把论文某几页圈出来让 AI 讲解；外文文献先全文翻译、再逐段对照精读。

## 入口与界面布局

### PDF 阅读器

**打开方式**：在资源库中双击任意教材或 PDF 文档（导入方法见 [资源库](/user-guide/learning-hub)）。学习桌面里会开成一个独立窗口，可以和对话窗口并排。

界面从上到下：

- **顶部工具栏**：目录、缩略图、书签、批注列表按钮；页码框（「第 x 页 / 共 y 页」）与上一页 / 下一页；缩放（放大/缩小/缩放级别菜单：适应宽度、适应页面、实际大小）；「更多」菜单里有旋转、单页/双页视图、封面单独成页、暗色阅读、文本选择开关、全屏和快捷键提示。
- **左侧侧栏**（按需展开）：目录、缩略图、书签、批注合并为同一侧栏的四个标签页，顶部图标切换——「目录」显示文档大纲点击跳转；「缩略图」按页面小图浏览；「书签」「批注」列表也在这里查看、编辑与删除，不再是互相遮挡的浮动面板。
- **中间阅读区**：支持滚动阅读。每页角落有一个选择框，勾选后可以把这几页交给 AI（见「选取页面问 AI」）；选中文字会弹出高亮色板和划词工具条（见下文）。

### 翻译工作台

**打开方式**：在资源库点「新建」→「新建翻译」，或双击已有的翻译资源。

界面分区：

- **顶部工具栏**：布局切换（左右/上下分栏）；语言选择（「源语言」「目标语言」，支持「自动检测」与二十多种语言）、交换语言按钮；「自动翻译」「同步滚动」开关与翻译设置入口。
- **主体双栏**：左侧「待翻译文本」输入区，右侧「翻译结果」；分栏比例可拖拽调整并自动记住，语向与语气偏好也会在新建翻译时自动恢复。窗口较窄时自动改为上下排列，「自动翻译」「同步滚动」开关收进设置面板。
- **对照视图**：切换「段落对照」后，原文与译文按段落逐一对齐显示。
- **翻译选项面板**：语气、翻译领域、自定义提示词、术语表（见"核心操作"）。

## 核心操作

### 阅读 PDF：翻页、缩放与视图

1. 用工具栏的上一页/下一页按钮或键盘 ← → 翻页；在页码框直接输入数字回车可跳页。
2. 缩放：点放大/缩小按钮，或 Ctrl/Cmd + ±；缩放级别菜单里可选「适应宽度」「适应页面」「实际大小」。
3. 宽屏阅读时点「双页视图」并排显示两页（窄窗口和触屏设备会自动收回「单页视图」）。书籍类 PDF 第 1 页通常是封面，可再点「封面单独成页」让封面独占一行，其余页按 [2,3] [4,5] 的真实对页排布，翻页也按此步进。
4. 夜间阅读点「暗色阅读」，页面反色护眼；「旋转」可顺/逆时针转 90°。
5. 阅读进度自动保存，下次打开同一文档会回到上次的页面；缩放档位（含适应宽度/页面等）、单双页视图和封面偏移也按文档记住，下次打开自动恢复。

### 搜索与目录导航

1. 点工具栏「搜索」（或按 Ctrl/Cmd + F），输入关键词。
2. 搜索是**边扫边出结果**的：找到第一个命中立即跳转并高亮，结果计数随扫描实时增长，搜索栏同时显示"已扫描 x/y 页"——几百页的大书不用等全书扫完。
3. 结果计数显示"当前 / 总数"，用「上一个」「下一个」在命中之间跳转，命中文本会高亮。
4. 点「目录」按钮打开侧栏大纲（部分 PDF 没有内置目录，会提示"此文档没有目录"）；侧栏顶部可切到「缩略图」按页面小图浏览跳转。

### 高亮批注

1. 确认「文本选择」处于开启状态，用鼠标选中一段文字。
2. 在弹出的色板中选择颜色：「黄色」「绿色」「蓝色」「红色」，即完成一条高亮批注；旁边的「复制」可以复制选中文字。
3. **修改已有高亮**：点页面上的高亮块会弹出操作浮层，可以换颜色（当前色有标记）或「删除批注」；触屏设备从底部操作条完成同样操作。保存失败时会有提示，不会静默丢失。
4. 点工具栏「查看批注」打开侧栏「批注」标签页，按页码排列，点击可跳转原文。
5. 注意：旋转视图下暂不支持划词高亮，请先恢复原始方向。

### 划词：解释、翻译、存笔记、制卡、发到对话

选中文字后，色板下方会出现划词工具条：

| 按钮 | 作用 |
|---|---|
| 解释 | AI 结合上下文讲解这段话的意思和关键表达，结果显示在弹出的卡片里 |
| 翻译 | 自动识别语向（可手动切换 / 对调），流式给出译文，并参考前后文消除多义词歧义；可以复制原文 / 译文 |
| 保存为笔记 | 以选中内容为引用块新建一条摘录笔记，末尾带「—— 摘自《资料名》第 N 页」，点它能回到原文那一页 |
| 制卡 | 把选中内容（连同前后文）送去 Anki 制卡，后台生成记忆卡片，放进「划词制卡::资料名」牌组；完成后通知里可以一键打开任务台 |
| 添加到聊天 | 把这段文字连同页码作为引用加进对话输入框，接着提问 |

解释和翻译的结果卡片上也有按钮，可以把 AI 的回答直接放进对话输入框。卡片管理与复习见 [Anki 制卡与模板](/user-guide/anki) 与 [闪卡复习](/user-guide/flashcards)。

### 书签

1. 翻到想标记的页面，点工具栏的「添加书签」。
2. 书签默认命名为"书签 - 第 x 页"，会自动打开侧栏「书签」标签页进入标题编辑，可直接改名。
3. 之后点「查看书签」（或侧栏顶部的书签图标）打开列表，点击任意书签即可跳页；不需要时点「删除书签」。

### 选取页面问 AI

这是「边读边问」的核心玩法：

1. 翻到想提问的页面，勾选页面角落的选择框（再点一次取消）；可以连续勾选多页，选择框旁会显示已选页数和上限（一次最多 10 页）。
2. 切到对话（学习桌面里把对话窗口和阅读窗口并排放），输入框上方会出现「第 x 页」的页码标签，连续页会合并成「1-3页」。
3. 输入问题（如「讲讲这两页的推导过程」）并发送，AI 会针对这些页作答。
4. 不需要时可以在输入框上方清空页码标签。

### 框选提问：截一块区域问 AI

页面上的公式、图表、扫描页里的题目选不了文字时，可以直接框出来问：

1. 点工具栏的「框选提问」（窄窗口在「更多」菜单里），阅读区会出现提示「拖动鼠标框出要问的区域（公式、图表都行）」；触屏上用手指拖。
2. 在页面上拖出一个框。框下的那部分页面会被截成图片，作为图片附件加进当前会话的输入框（和粘贴图片一样），提示「已引用到对话」，可以点「去对话」切过去。还没打开对话时，截图会在你打开对话后出现在输入框里。
3. 一次只截一页：框跨了两页时，取框住面积更大的那一页。高亮等批注不会被截进去。
4. 截完自动退出框选；中途不想截了，按 `Esc` 或点「取消」。页面还没渲染完时会提示稍等再框。

图片提问需要当前模型支持读图，见 [AI 对话与会话管理](/user-guide/chat)。

### 页码引用跳转

AI 的回答用到你的 PDF 时，会附带页码引用。点引用徽章或引用的页面缩略图，阅读器会打开到对应页面，并在页面上高亮被引用的那句话，方便核对原文。

### 阅读 Word / EPUB / 其他文档

- **Word（DOCX）**：双击打开即渲染为分页的「白纸」版式，工具栏可以「增大字号 / 减小字号 / 重置字号」。正文可以选中并划词，引用会带上「第 N 节」。加密文档或旧版二进制格式（.doc / .xls / .ppt）无法预览，会提示用办公软件打开。
- **PPT（PPTX）**：按幻灯片预览，同样可以划词，引用带「第 N 张幻灯片」。
- **EPUB 电子书**：支持「目录」侧栏、书内搜索、「上一章 / 下一章」；「阅读主题」可选明亮 / 护眼 / 深色 / 跟随应用；「排版设置」可调字号、字体、行距、页边距。选中文字同样有划词工具条，引用带「第 N 章」。窗口较窄时目录自动收起，留出阅读空间。阅读进度按章节随资料保存，换设备或清理缓存后重开仍能回到上次读到的地方。
- **Excel / 文本 / 音视频**：见 [资源库](/user-guide/learning-hub) 的预览说明。

### 全文翻译

1. 打开翻译工作台，把原文粘贴进「待翻译文本」，或直接**拖拽文件**（支持图片、PDF、DOCX、TXT、MD）到输入区——图片走 OCR 识别，文档自动解析出文本。
2. 选择源语言（默认「自动检测」）和目标语言。
3. 点「翻译」按钮或按 Ctrl/Cmd + Enter，译文流式出现在右侧「翻译结果」。
4. 翻译完成后可以：「复制」译文、「导出」为 Markdown/文本文件、「编辑译文」手动修正、「朗读」听发音，或为本次翻译打星评分。
5. 单次翻译上限 5 万字符，超出会自动截断；拖入的文件最大 50MB。

> 翻译用的模型在「设置 → 模型分配 → 翻译专用模型」里指定（不设置就用对话模型），见 [模型与供应商配置](/user-guide/models)。

### 逐段双语对照

1. 翻译完成后，打开「段落对照」（对照视图）。
2. 原文与译文按段落一一对应显示，适合精读比对；若两侧段落数不一致，系统会按句子启发式对齐并提示。
3. 译文结果区和段落对照里的文字都可以选中，选中后弹出和 PDF 一样的划词工具条：「解释」「翻译」「保存为笔记」「制卡」「添加到聊天」——读外刊时遇到生词可以直接查、直接制卡；添加到聊天的引用会标明来自这篇翻译，点它能在对话右侧重新打开。

### 领域预设与自定义提示词

打开「翻译选项」面板：

1. **语气**：「自动 / 正式 / 非正式」。
2. **翻译领域**：7 种预设——「通用」「学术论文」「技术文档」「文学作品」「法律文书」「医学文献」「日常对话」，选择后会针对该领域优化术语与行文。
3. **自定义提示词**：在默认规则之外补充要求（如"保留所有专有名词英文原文"），随每次翻译发送给模型；可「恢复默认」。常用组合还能「存为模板」复用。切换翻译领域时，提示词的默认文案会自动跟随新领域的模板；只有你**显式修改过**的提示词才会作为覆盖项固定下来、不随领域切换变化。
4. **术语表**：添加"原文术语 → 目标译法"条目，翻译时严格遵守——适合固定教材术语的译法。

### 翻译记录管理

每篇翻译都会自动保存为资源库里的一个翻译资源，并按原文第一句自动命名：在资源列表中可搜索、收藏、重命名、移动到科目文件夹或删除；双击即可回到工作台继续编辑。关闭带有未保存修改的翻译窗口时，会询问「保存并关闭 / 丢弃 / 取消」。

## 进阶用法

- **翻译 + 阅读联动**：读到不懂的句子直接划词「翻译」或「解释」；需要整段精读时把文字复制进翻译工作台，再勾选页面让 AI 讲解原文。
- **保存即资源**：每篇翻译都是资源库里的一个资源，可收藏、移动到科目文件夹、被 AI 引用检索。

## 📱 移动端说明

**PDF 阅读**：

- 手势：**双指捏合**缩放、**双击**放大/还原、上下滑动翻阅；PDF 区域不会触发应用的左右切屏手势。
- 「双页视图」在手机上不提供（窄屏自动回到单页），「封面单独成页」入口也随之隐藏。
- 划词：长按选中文字后，同样可以选高亮颜色，并使用「解释」「翻译」「保存为笔记」「制卡」「添加到聊天」；当前场景用不了的按钮会自动隐藏。
- 目录/缩略图/书签/批注在小屏上以全屏子页面展开（顶部四个分段切换），选择后自动返回阅读。
- 页面勾选照常可用，选中的页码同样会出现在聊天输入栏。
- 「框选提问」在「更多」菜单里，用手指拖出区域即可。

**翻译工作台**：

- 原文/译文双栏在窄屏自动变为**上下堆叠**布局；其余功能（领域预设、术语表、对照视图）与桌面一致。
- 朗读功能依赖系统语音合成，部分设备可能提示"当前浏览器不支持语音合成"。

**DOCX / EPUB**：阅读与排版调节功能与桌面一致，工具栏为紧凑样式。

更多移动端通用操作见 [移动端指南](/user-guide/mobile)。

## 常见问题

**Q1：打开 PDF 提示"该 PDF 已加密或需要密码"？**
若知道密码，在弹出的密码框输入即可打开；受版权保护无法解密的文件请先在其他工具中解除保护再导入。

**Q2：PDF 很大打不开或加载很慢？**
超过 100MB 的 PDF 会停止预览并提示改用系统阅读器；较大的文件首次加载偏慢属正常，之后有进度记忆。若提示"文件路径可能已失效"，用「重新关联文件」指向文件的新位置。

**Q3：为什么选不中 PDF 里的文字、没法高亮？**
两种可能：一是「文本选择」开关未开启；二是这份 PDF 是扫描版（没有文字层）——可先在资源库的「知识库索引」中完成 OCR 索引让 AI 能读到内容，但阅读器内的划词高亮仍需文字层。

**Q4：高亮和书签会丢吗？**
不会，都会随资源保存，下次打开自动恢复。注意高亮位置依赖页面版式，请在同一文档内查看。

**Q5：翻译结果不满意怎么办？**
依次尝试：选对「翻译领域」预设；在「术语表」固定关键术语译法；用「自定义提示词」描述风格要求；必要时到「设置 → 模型分配」换一个能力更强的翻译模型。也可以点「编辑译文」手动修正，修改会保存进历史。

**Q6：翻译需要联网吗？**
发起新翻译需要。翻译调用你配置的 AI 模型服务，离线时会提示网络错误；使用本地模型服务（如 Ollama）则可离线。已翻译内容的**本地操作不受离线影响**：编辑译文保存、质量评分、关窗时的「保存并关闭」都是本地写入，断网时照常可用。
