# 命令面板与快捷键

## 概述

命令面板是 DeepStudent 的效率中心，通过键盘即可触达应用的所有功能。

- 按 `Cmd + K`（macOS）或 `Ctrl + K`（Windows/Linux）打开命令面板，输入关键词执行命令。
- 按 `Cmd/Ctrl + P` 打开**全局搜索**，跨笔记、会话、文档搜索内容。
- 也可点击侧边栏顶部的「**搜索与命令**」进入。

> 下文快捷键统一写作 `Mod`：macOS 上是 `Cmd`，Windows/Linux 上是 `Ctrl`。

## 快捷键附录

### 全局与导航

| 快捷键 | 功能 |
|--------|------|
| `Mod + K` | 打开命令面板 |
| `Mod + P` | 全局搜索（笔记/会话/文档） |
| `Mod + 1` | 前往新会话 |
| `Mod + Shift + 7` | 前往学习资源 |
| `Mod + Shift + 6` | 前往制卡任务 |
| `Mod + 5` | 前往数据统计 |
| `Mod + E` | 前往数据管理 |
| `Mod + ,` | 前往设置 |
| `Mod + [` / `Mod + ]` | 后退 / 前进 |
| `Alt + ←` / `Alt + →` | 后退 / 前进 |
| `Mod + Shift + H` | 回到首页（新会话） |
| `Mod + Shift + T` | 切换亮/暗主题 |
| `F11` | 切换全屏 |
| `Mod + =` / `Mod + -` / `Mod + 0` | 放大 / 缩小 / 重置界面缩放 |
| `Mod + Alt + R` | 重新加载应用 |
| `Mod + L` | 锁定应用 |
| `F1` | 帮助文档 |

### 对话（新会话页内）

| 快捷键 | 功能 |
|--------|------|
| `Enter` / `Shift + Enter` | 发送消息 / 换行 |
| `Mod + N` | 新建对话 |
| `Mod + Shift + A` | 新建题目分析会话（上传图片识别题目） |
| `Mod + S` | 保存对话 |
| `Mod + .` | 停止生成 |
| `Mod + R` | 重新生成上一条回复 |
| `Mod + Shift + C` | 复制上一条回复 |
| `Mod + Shift + R` | 切换 RAG（资料检索） |
| `Mod + Shift + W` | 切换联网搜索 |
| `Mod + Shift + G` | 切换图谱模式 |
| `Mod + Shift + I` | 上传图片 |
| `Mod + \` | 切换历史侧栏 |
| `Mod + Shift + \` | 切换功能面板 |
| `Mod + J` | AI 续写 |
| `Mod + /` | 快速提示词 |

### 学习资源与其他

| 快捷键 | 功能 |
|--------|------|
| `Mod + T` | 打开翻译工作台（学习资源页内） |
| `Mod + Shift + Space` | 语音听写（按住说话，默认值，可在设置中修改） |

### 思维导图（导图编辑器内）

| 快捷键 | 功能 |
|--------|------|
| `Mod + Z` / `Mod + Shift + Z` | 撤销 / 重做 |
| `Mod + F` | 在导图中搜索 |
| `Tab` / `Enter` | 添加子节点 / 同级节点 |

## 常用命令

命令面板中除了带快捷键的命令外，还有大量可搜索执行的命令，例如：

- **导航**：跳转到模板库、技能管理、PDF 阅读器
- **对话**：清空对话、选择 AI 模型、导出/导入对话、从此处分支、收藏对话
- **资源**：新建笔记、新建文件夹、搜索笔记、打开作文批改

输入命令名称的任意片段即可模糊匹配。

## 自定义快捷键

1. 打开 **设置 → 快捷键**。
2. 找到目标命令，点击编辑按钮。
3. 按下你想要的组合键，自动保存。
