# AI 对话与会话管理

> 与 AI 围绕你的学习资料展开多轮对话，并用课题分组、标签、搜索和导出把每一次对话都管理好。

## 功能概览

AI 对话是 Deep Student 的核心入口。它不只是一个聊天窗口，你可以在这里：

- 与 AI 多轮对话，随时附上图片、PDF、Word 等资料一起提问
- 引用资源库里的笔记、教材、题目集，回答带出处，点引用直接跳回原文那一页
- 开启推理模式（思维链），查看 AI 的完整思考过程
- 让多个模型同时回答同一个问题并排对比（实验性）
- 从任意一条回答「从此处分支」，探索不同的解题路径
- 用「问一问 / 想一想 / 做一做」三档权限控制 AI 能做多少事
- 把会话整理进课题（分组），配置分组专属的系统提示词、默认技能和资料
- 搜索、置顶、归档、导出任意会话

适合的场景：解题答疑、围绕教材提问、整理资料、让 AI 帮你生成导图 / 题目 / 闪卡（详见对应章节），以及一切「想问点什么」的时刻。

## 入口与界面布局

学习桌面里点 Dock 的「对话」打开对话窗口；经典布局下，打开应用默认就是对话页（左侧导航的「新会话」）。界面分为三个区域：

- **左侧会话栏**：顶部是「新对话」和「所有对话」；下面依次是「课题」（会话分组，可以设颜色）、「置顶会话」、最近会话（按今天 / 昨天 / 最近 7 天等分组）、「未分组」和「已归档会话」入口。右上角「筛选会话」可以选择是否「显示子代理会话」（默认隐藏）。
- **中间消息区**：显示对话内容。新会话是空状态页，标题为「开始对话」，下面给出几条示例任务，点一下就能填进输入框。有到期的闪卡时，输入框下方会显示「今日待复习」，点一下直接开始复习。
- **底部输入栏**：输入框（占位提示「输入消息...」）和一排按钮：「＋」菜单、模型选择、推理模式、语音输入、发送等。

小提示：随时按 `Ctrl / ⌘ + N` 新建对话。

## 核心操作

### 发送一条消息

1. 点击底部输入框，输入问题。
2. 按 `Enter` 发送，`Shift + Enter` 换行；中文输入法选字时按 Enter 不会误发送。
3. AI 回复过程中，发送按钮会变成「停止」，点击可中断生成。
4. AI 回复时继续输入并发送，新消息会自动排队，等当前回复结束后按顺序发送。在「排队模式」里切换为「引导」后，排队的气泡上会出现「引导」按钮，点击可打断当前回复、优先处理这条消息。

### 「＋」菜单里有什么

点输入框左侧的「＋」（「添加与会话选项」），可以找到：

| 菜单项 | 作用 |
|---|---|
| 添加文件 | 「添加附件」从电脑选文件；「资源库」引用已导入的资料；移动端还有「拍照」 |
| 模式 | 切换「问一问」「想一想」，以及「做一做执行档位」（见下文权限一节） |
| 知识库 | 「主动检索」：回答前先查你的笔记、教材等本地资料；还可以限定只在某个课程或文件夹里检索 |
| 连接器 | 选择本次对话可以用的 MCP 服务器等外部工具（见 [技能与 MCP 扩展](/user-guide/skills-mcp)） |
| 技能 | 查看和激活技能 |
| 对话控制 | 调整温度、上下文长度等参数（见「进阶用法」） |
| 压缩上下文 | 手动把较早的对话压缩成摘要，给长对话腾出空间 |

### 上传附件（图片 / PDF / Word 等）

1. 「＋」→「添加文件」→「添加附件」选择文件；也可以直接把文件拖进窗口，或粘贴剪贴板里的图片。
2. 大小与数量限制：单个附件最大 200MB，图片最大 50MB；一条消息最多 20 个附件。超限的附件会被拒绝并给出提示。
3. 附件以缩略图形式出现在输入栏上方，处理过程中显示进度（提取文本、渲染、OCR、索引等阶段）。
4. 点附件旁的「注入」标签可以切换注入方式：
   - 图片：「图片」（把原图交给模型，需要多模态模型）或「OCR」（只给识别出的文字）
   - PDF：「文本」（提取的文字）、「OCR」或「图片」（整页截图，需要多模态模型）
5. 当前模型不支持图片输入时，应用会自动把图片附件切换为文字 / OCR 方式并提示你。
6. 粘贴超长文本时会提示「已粘贴长文本」，可以选择「转为附件」或「保留文本」。

输入栏角落会实时显示本次消息的 Token 估算（如「约 1200 tokens / 上下文」），帮你判断内容是否过长。

### 引用资源库中的资料

1. 「＋」→「添加文件」→「资源库」，挑选笔记、教材、题目集或整个文件夹（资料要先导入，见 [资源库](/user-guide/learning-hub)）。
2. 选中的资料以「引用内容」小卡片显示在输入栏上方，点击可预览，也可以逐个移除或「清空所有引用」。标记为「持久引用」的资料会在之后每一轮对话里持续生效。
3. 也可以从资料那边发起：在 PDF、Word、EPUB 里选中一段文字，点划词工具条的「添加到聊天」；或者在 PDF 页面角落勾选几页，页码会以标签形式出现在输入框上方（详见 [文档阅读与翻译](/user-guide/reading-translation)）。

### 查看出处，跳回原文

AI 引用了你的资料时，回答里会出现引用徽章（如 `[1]`、「第 4 页」）：

- 点徽章或引用的页面缩略图，会直接打开原文并跳到对应页，被引用的那句话会在页面上高亮。
- 引用的是思维导图时，会打开导图并定位到对应节点；引用的是笔记中的一段时，会滚到那一小节。
- 资料已经被删除或引用信息不完整时，会提示「无法打开 PDF 引用」等原因，而不是点了没反应。

### 选择模型与多模型对比（实验性）

1. 点输入栏上的模型名称，打开「选择模型」面板；可以按名称或模型 ID 搜索，也可以把某个模型「设为系统默认」。
2. 打开面板里的「对比模式」开关（「同时使用多个模型回答」），勾选多个模型后发送，多个回答会并排显示。
3. 也可以在输入框里输入 `@` 加模型名称来指定模型；选了多个就自动进入「多模型并行」。
4. 并行生成时可以「全部停止」；结束后用「上一个变体 / 下一个变体」切换查看，不满意的变体可以单独「重试」或「删除」。
5. 对已有回答不满意时，点消息下方的「重试」，可以在「选择模型重试」里换一个模型，或选多个模型「并行重试」。

模型要先在设置里配置，见 [模型与供应商配置](/user-guide/models)。

### 开启推理模式（思维链）

1. 点输入栏上的「推理模式」按钮开启（不支持推理的模型会显示「不支持推理」）。
2. 点旁边的深度菜单选择「推理强度」：低 / 中 / 高 / 超高（越高越慢）。部分模型（如通义千问）还有更高的档位。
3. 开启后，回答上方会出现「思维链」区块，显示「正在思考 N 秒…」，点击可展开完整推理过程。

### 权限模式：问一问 / 想一想 / 做一做

AI 在对话中可以调用工具（写笔记、执行命令、操作文件等）。权限在「＋」→「模式」里切换，共三档：

- **问一问**：打开「问一问」开关进入只读模式，所有写入类工具都会被拒绝，适合纯提问。
- **想一想**：打开「想一想」开关后，AI 执行写操作前会先弹出「确认执行计划」卡片，你点「确认执行」后才继续（超时自动拒绝）。
- **做一做**（默认）：两个开关都不开就是这一档，由「做一做执行档位」决定哪些操作要你确认。默认的「宽松」只对高风险或无法判断风险的操作弹出「工具执行确认」卡片。

确认卡片上可以选「本次允许」或「拒绝」；策略允许时还会提供「本会话允许」（只在本会话内有效，应用重启后失效），没有跨会话的「始终允许」。拒绝时可以写原因，告诉 AI 该怎么改。

「做一做执行档位」共四档：

- **谨慎**：中高风险操作逐项确认，不提供「本会话允许」。
- **宽松**（默认）：低风险和中风险操作直接执行，高风险操作仍逐项确认。
- **完全访问**：工具和命令行不再逐步确认，本地命令行也不再受工作目录、文件和网络沙箱的限制；安装技能 / MCP 等特权操作仍会单次确认，可识别的灾难性命令始终拒绝。开启后输入栏会出现「完全访问」角标，点一下即可降回宽松。
- **危险完全访问**：本地命令行完全不设限，命令规则、灾难命令防护、环境变量过滤、超时和输出上限全部关闭，只保留取消和进程回收；特权操作仍单次确认。开启前会弹出强警告，输入栏显示红色「危险访问」角标，点一下立即降回宽松。除非你清楚自己在做什么，否则不要开启。

档位只约束「做一做」；问一问 / 想一想本身的限制始终优先。新会话会记住你上次选的「谨慎」或「宽松」；「完全访问」和「危险完全访问」只对当前会话生效，不会变成新会话的默认档。

### 消息的常用操作

鼠标悬停在任意消息上（移动端点消息旁的菜单按钮），可以：

1. 「复制」消息文本。
2. 「编辑」你发过的消息并「重发」，对话从这条消息重新继续。
3. 「重试」让 AI 重新回答（会提示将删除后续消息）。
4. 「删除」这条消息（有确认弹窗）。
5. 「保存为笔记」：把回答存进笔记库，笔记里会保留来源，之后可以一键回到这条消息（见 [笔记](/user-guide/notes)）。
6. 「导出为 Markdown」：把这条回答导出为 .md 文件。
7. 「从此处分支」：以当前位置为起点复制出一个新会话，原会话不受影响，适合探索不同解法。原消息上会出现「已从此处分支」角标，点击可跳到分支会话。

选中消息里的一段文字，会浮出快捷工具条：「复制」「解释」「翻译」「添加到聊天」。

### 用课题（分组）组织会话

1. 在左侧「课题」区域点「新建分组」。
2. 填写「分组名称」，可选填「分组描述」「分组图标」「分组颜色」（14 种预设色）。
3. 「分组 System Prompt」：该分组下的会话默认带上的系统指令，例如「你是我的考研数学教练」。
4. 「默认技能」：该课题下所有新会话预先激活的技能。
5. 「关联来源」：点「浏览资源」挑选资料，这些资料会在该分组的所有会话里自动作为上下文。
6. 「默认项目目录」（进阶）：给课题绑定一个文件夹，作为 AI 可以读写的工作区。
7. 保存后，在分组上点「在 ×× 中新建会话」即可创建带上述配置的会话。分组支持置顶、重命名和归档。

### 管理单个会话

在会话条目上右键（或点条目上的「…」）：

- 「重命名线程」：修改标题（`Enter` 保存，`Esc` 取消）
- 「置顶线程」/「取消置顶」
- 「移动到分组」：把会话归入某个课题
- 「归档线程」：从列表里隐藏，可以在设置里的「已归档会话」中查看和恢复
- 「删除会话」：永久删除，不可恢复
- 「导出会话」：把整个会话导出成文件
- 「在新窗口打开」（仅学习桌面）：给这个会话单独开一个窗口，和其他会话并排对照

### 搜索与浏览所有会话

1. 点会话栏顶部的「所有对话」，进入会话浏览视图。
2. 顶部可以切换「按时间分组 / 按分组浏览 / 按工作区浏览」。
3. 搜索框有两种模式：「标题」（匹配标题、简介、标签）和「内容」（全文搜索对话内容，显示命中片段）。
4. 「按标签筛选」按标签过滤；在会话卡片上可以直接「添加标签」或移除标签。
5. 卡片上会显示 AI 任务状态（进行中 / 已阻塞 / 已完成）和产物数量，悬停卡片可以直接「导出会话」。
6. 别处导出的会话快照可以用「导入会话快照」导回来。

## 进阶用法

- **对话控制**：「＋」→「对话控制」可以调整「温度」「Top-P」「上下文长度」「最大输出」「频率惩罚」「存在惩罚」，以及知识库检索配置（Top-K、重排、多模态检索）。这些参数只影响之后新建的对话。
- **技能斜杠命令**：在输入框开头输入 `/` 会弹出「技能命令」列表，回车即可为这条消息激活某个技能（如 `/research-mode`），已激活的会标注「已激活」。详见 [技能与 MCP 扩展](/user-guide/skills-mcp)。
- **语音输入**：点麦克风按钮录音，松开后自动转写进输入框。目前转写只支持 SiliconFlow：先在「模型服务」配好 SiliconFlow 密钥，再在「模型分配」里选择「语音识别（ASR）模型」（一键分配会自动配好）。
- **生成图片**：直接描述需求（如「帮我画一张细胞结构示意图」），AI 会调用生图工具产出示意图、插图等。需要先在「模型分配」里配置生图模型。
- **产物**：AI 在对话里生成的看板、卡片组、笔记和文件会收进会话底部的「产物」列表，点开可以预览或「保存到笔记库」；不想要的产物文件可以「撤销写入」删掉。
- **子代理（实验性）**：复杂任务里 AI 可能派出子代理在后台分头工作，消息流里会出现子代理卡片，点「查看完整会话」可以看它的完整过程。
- **上下文压缩**：对话很长时，较早的内容会自动压缩成「上下文已压缩 · 学习状态摘要」卡片，点击可展开；原始消息仍完整保存，只是不再占用模型上下文。也可以随时用「＋」→「压缩上下文」手动压缩。上下文接近上限时会建议新开会话或精简引用内容。
- **Token 统计**：每条回答下可以查看本条与本会话累计的 Token 用量、缓存命中和费用估算。

## 在学习桌面中使用对话

- 「对话」是一个窗口：点 Dock 图标打开或切到它，窗口左侧是会话列表。
- 想同时看两个会话，在会话的「…」菜单里选「在新窗口打开」，同一个会话不会重复开窗。
- 从子代理卡片、通知、全部应用（`⌘K` / `Ctrl+K`）等地方跳转到某个会话时，会自动切到对话窗口并打开那个会话，窗口还在加载也不会跳错。
- `Ctrl / ⌘ + N` 和全部应用里的「新建对话」在任何时候都有效。

学习桌面的通用操作见 [学习桌面](/user-guide/workbench)。

## 📱 移动端说明

- **布局**：移动端为三屏结构。中间是对话；点左上角 ☰ 或从屏幕左边缘右滑打开会话抽屉（新对话 / 课题 / 最近 / 未分组 / 已归档）；从右边缘左滑打开资源库面板。
- **返回键**：Android 返回键按「浮层 → 面板 → 抽屉 → 页面」的顺序逐层关闭，不会直接退出应用。
- **会话操作**：会话条目上点「…」可以重命名、置顶、归档、删除，也支持滑动手势快速置顶或删除。「所有对话」在抽屉导航里也有入口。
- **消息操作**：消息旁常显复制按钮，其余操作（重试 / 保存为笔记 / 从此处分支 / 删除等）收在「…」菜单里。
- **输入栏**：「＋」→「添加文件」里多了「拍照」；技能、对话控制、推理深度等面板会贴着输入栏弹出。
- **多模型对比**：并行回答以横向卡片轮播呈现，左右滑动逐个查看。
- **键盘**：软键盘弹出时，抽屉手势会暂时屏蔽以防误触，收起键盘后恢复。

更多移动端操作见 [移动端指南](/user-guide/mobile)。

## 常见问题

**Q1：发送按钮是灰的 / 提示「当前会话尚未就绪」？**
通常是还没有配置对话模型。到「设置 → 模型分配」选好对话模型即可，详见 [模型与供应商配置](/user-guide/models)。第一次配好供应商后，应用也可能自动分配并提示「已自动将 ×× 设为默认对话模型」。

**Q2：上传了图片，AI 却说看不到图？**
当前模型可能不支持图片输入，应用会把图片自动降级为 OCR 文字。想让模型直接「看图」，在「选择模型」面板换一个多模态模型，并把附件的注入方式切回「图片」。

**Q3：AI 回答到一半卡住了怎么办？**
先点「停止」，再点这条消息的「重试」。如果提示「流式响应超时」，应用会自动重置状态，重新发送即可。

**Q4：删除的会话能找回吗？归档和删除有什么区别？**
「删除会话」是永久删除、不可恢复；「归档线程」只是从列表隐藏，随时可以在设置里的「已归档会话」中恢复。不确定时建议用归档。

**Q5：怎么把一次有价值的对话保存下来？**
单条回答用「保存为笔记」或「导出为 Markdown」；整个会话在会话菜单或「所有对话」的卡片上用「导出会话」。

**Q6：「问一问」模式下 AI 说操作被拒绝了？**
这是预期行为：问一问是只读档位，所有写入操作都会被拦截，并提示「当前为问一问模式，写操作已被拒绝」。点提示旁的「切换到想一想」，AI 就会在你确认计划后执行。

**Q7：AI 回答没有引用我导入的资料？**
确认资料已在资源库的「知识库索引」里显示「已索引」，并且配好了嵌入模型（见 [模型与供应商配置](/user-guide/models)）。想让 AI 每次都先查资料，打开「＋」→「知识库」→「主动检索」；或者直接用「资源库」把资料引用进对话。
