# 音视频

> 「音视频」把网课、讲座、录音变成可检索、可提问、可复习的学习材料：转写出带时间戳的字幕，边看边查、边看边问，一键整理讲义、制卡、出题，回答和卡片里的时间点点一下就跳回视频。

## 功能概览

- **转写与字幕**：把音轨转成带时间戳的字幕，可搜索、点句跳转、播放时跟随高亮；已有字幕文件可以直接导入，不花转写费用。
- **B 站链接**：贴一个 B 站视频链接，拉取 UP 主上传的字幕或 B 站自动生成的 AI 字幕，不下载视频就能检索、提问、生成讲义，视频直接在应用里播放。
- **边看边问**：就这节课向 AI 提问，回答带 `▶ 01:23 · 文件名` 这样的时间戳引用，点一下回到那一刻；看不懂的画面可以截帧发给 AI。
- **讲义、闪卡、题目**：一键生成图文讲义（保存为笔记，可导出 Word），或基于字幕制卡、出题，卡片和题目都注明出处时间点。
- **进度与时长**：断点续播、观看时长、是否看完，学习时长计入学习热力图。

「音视频」不是另一个文件仓库，而是**资源库的专用视角**：音视频文件仍然存放在资源库里，备份、同步、搜索都和其他资料一样；这里只是把"看一门课"需要的步骤串在一起。产出的内容分别落在 对话、笔记、闪卡、题目集 里。

## 入口

| 位置 | 怎么进 |
|---|---|
| 学习桌面 | Dock 或「全部应用」里的「音视频」 |
| 经典布局 | 左侧导航的「音视频」（在「资源库」下面） |
| 命令面板 | 搜索「前往音视频」 |
| 资源库 / 对话右侧面板 | 打开一个音视频文件后，工具栏上的「在音视频中学习」 |
| Android | 抽屉应用启动器里的「音视频」 |

## 快速上手

1. **导入**：打开「音视频」，点「导入音视频」选择文件（电脑上也可以直接把文件拖进页面）；B 站上的课程点「B 站链接」贴链接即可，不用下载。
2. **转写**：在列表里点开这节课，在「字幕」标签点「转写」，确认预计时长和费用后开始；已有字幕的话点「导入字幕」即可（从 B 站链接导入的课自带字幕，不需要转写）。
3. **学习**：边看边在「问答」标签提问，看完在「讲义」生成讲义，在「练习」制卡或出题。

## 媒体库（首页）

首页列出资源库里所有的音频和视频，按最近活动排序，最近看过、刚导入或刚转写的排在前面。

- **导入音视频**：点「导入音视频」（电脑在顶栏右侧，手机在页面底部），用系统文件选择框选择文件，可以一次选多个；电脑上也可以把文件拖到页面上。导入时列表顶部显示「正在导入 1/3：文件名」（手机上带进度条）。只导入一个文件时，完成后直接进入它的学习页。导入的文件放在资源库的根目录，在「资源库」里同样能看到。
- **B 站链接**：点「B 站链接」（在「导入音视频」旁边），粘贴视频页地址、`b23.tv` 分享短链或 BV 号，点「解析」。弹窗显示标题、UP 主和时长；字幕有多条时可以选择用哪一条，默认优先 UP 主上传的中文字幕，其次 B 站自动生成的 AI 中文字幕。合集 / 多 P 视频会列出全部分 P，默认勾选链接里的那一 P（链接带 `?p=` 时），可以「全选」或勾选多 P 一次导入，每 P 一个条目。只导入一个时，完成后进入它的学习页。详见下文「[B 站链接](#b-站链接)」。
- **搜索与筛选**：按名称搜索；用「全部 / 在看 / 未转写 / 已转写」筛选。
- **按分组看**：搜索框右侧可以在「列表」和「按分组」之间切换。分组就是这些音视频在资源库里所在的文件夹，每个分组可以折叠，没放进文件夹的在最后的「未分组」里；筛选和搜索在分组里照样生效。
- **多选与全选**：点顶部「选择」进入多选，每行出现勾选框（在行上长按也能进入）。底部操作条显示「已选 N 项」，可以「全选」当前列出的条目（先筛选或搜索再全选，只选中看得到的）、「移动到分组…」（选已有分组、「新建分组…」或「移出分组」；新建时会用所选条目的共同标题作默认名，比如同一门课的几个分 P）、「删除」。按 Esc 或点「完成」退出。按分组看时，分组标题上的勾选框可以一次选中整组。
- **每一行显示**：缩略图（B 站条目是视频封面，底边是观看进度）、名称、时长、转写状态、观看进度条和上次观看时间。转写状态有：「未转写」「排队中」「转写中 n/m」「已转写」「已导入字幕」「部分完成」「转写失败」。看完的课名称旁有一个对勾；B 站链接条目带「B 站」标记。
- **行菜单「⋯」**：
  - 「导入字幕文件…」：导入 `.srt`、`.vtt` 或 B 站字幕 JSON；
  - 「从 B 站链接获取字幕…」（本地音视频）：贴同一视频的 B 站链接，把 B 站上的字幕导入进来，替换现有字幕；B 站链接条目这里是「重新获取 B 站字幕…」，可以换一条字幕或拉取更新后的字幕；
  - 「导出为 SRT」「导出为 WebVTT」「导出为纯文本」：导出字幕（有字幕后可用）；
  - 「重命名」；
  - 「在资源库中显示」：在资源库里打开这个文件；
  - 「删除」：移入资源库的回收站，可以在回收站恢复。

还没有任何音视频时，页面会介绍三项能力（转写与字幕 · 边看边问带时间戳引用 · 一键讲义与制卡出题），并提供导入按钮。手头已有字幕文件的课程，导入字幕就能用全部功能，不需要付费转写。

支持 MP4、MOV、MKV、M4A、MP3、WAV、FLAC 等常见格式，单个文件最大 4GB。

## 学习页

在首页点一节课进入学习页：左边是播放器，右边是四个标签——「字幕」「讲义」「问答」「练习」（窗口较窄时标签面板移到播放器下方）。顶栏左侧的返回箭头回到首页。

播放器上方的工具栏：

- 「转写」：开始转写；转写中显示进度，可以「取消」；
- 「截取当前帧」（视频）：把当前画面引用到对话里，配合提问使用；
- 「在 B 站打开」（B 站链接条目）：在浏览器里打开这个视频，从当前位置开始；
- 「⋯」：「导入字幕文件…」「从 B 站链接获取字幕…」（链接条目为「重新获取 B 站字幕…」）和三种字幕导出。

下次打开会从上次看到的位置继续播放。

### 字幕

- 显示带时间戳的字幕，可以**搜索**；**点任意一句**跳到对应位置；
- 播放时自动**跟随当前句**并高亮；你手动滚动字幕时会暂停跟随，方便往回翻；
- 画面上也会叠加字幕，可随时关闭；
- 还没有字幕时，这里显示「转写」和「导入字幕」两个按钮。

### 讲义

- 列出由这节课生成的所有讲义笔记，点一篇即在笔记中打开；
- 「生成讲义」：AI 结合字幕和关键画面（视频）整理成一篇图文讲义，保存为笔记，每个小节开头有可点击的时间锚点。需要先有字幕；
- 讲义就是普通笔记，可以继续编辑，也可以在笔记的导出菜单中导出为 Word（含「讲义 / 公文」版式），详见 [笔记](/user-guide/notes)。

### 问答

- 「就这门课提问」：新开一个对话，自动引用这节课，并已启用「课程学习」技能——AI 会先检索字幕再回答，回答里带时间戳引用；
- 常用问题：「总结这节课」「列出重点和难点」「解释我没听懂的地方」，点一下新开对话并把问题预填好，确认（或补充时间点）后发送；
- 回答里的 `▶ mm:ss` 时间戳点一下，播放器就跳到那一刻。

### 练习

- 「制作闪卡」「生成练习题」：新开一个对话，引用这节课、启用「课程学习」技能，并在输入框里预填好指令。你可以先改一改（比如"只出 10 道选择题"），确认后再发送；
- 生成的卡片进入「闪卡」，题目进入「题目集」，都注明出处时间点，复习时可以一键跳回视频（参见 [Anki制卡与模板](/user-guide/anki)、[题目集与练习](/user-guide/question-bank)）；
- 下方显示这节课的学习进度：观看时长、是否看完、字幕段数等统计。

## 转写与字幕

### 转写

1. 在「字幕」标签或工具栏点「转写」。
2. 弹窗显示时长、预计段数和所用模型，确认后开始。转写按语音识别的调用量计费，所以每次都会先让你确认。
3. 应用在本机解码音轨、按停顿切分语音段，再逐段识别；进度显示在工具栏和首页的状态里。

- **在后台进行**：转写开始后可以切到别的页面、去看别的课，转写会继续；首页的状态会随之更新，应用从后台切回前台时也会刷新。
- **可以取消、可以续做**：取消或中断后，已完成的段会保留，下次点「转写」从没做完的地方继续；部分段失败时状态显示「部分完成」，再转写一次会补上失败的段。
- **短音频自动转写**：10 分钟以内的短音频，导入后会自动开始转写。
- **需要先配置语音识别模型**：转写和对话里的「语音输入」共用同一个模型，在「设置 → 模型分配」中选择「语音识别（ASR）模型」，硅基流动、阿里云百炼（`qwen3-asr-flash`）、OpenAI 和 OpenAI 兼容的中转站都可以；用硅基流动一键分配会自动配好 Qwen3-ASR。没分配时，配好硅基流动密钥就会用默认的 `Qwen/Qwen3-ASR-1.7B`。详见 [模型与供应商配置](/user-guide/models)。

### 导入与导出字幕

- **导入**：首页行菜单或学习页「⋯」→「导入字幕」，支持 `.srt`、`.vtt` 和 B 站字幕 JSON。不调用模型，不产生费用，导入后同样能检索、提问、生成讲义。
- **导出**：「导出字幕」→ SRT / VTT / 纯文本，方便用在其他播放器里或分享给同学。

### B 站链接

不用下载视频，贴链接就能把 B 站上的课变成学习材料：

- **字幕从哪来**：UP 主上传的字幕，或 B 站为视频自动生成的 AI 字幕。用 B 站的网页接口，**不登录也能用**，也不下载音视频。
- **登录 B 站（可选）**：「B 站链接」弹窗顶部有一行账号状态，点「扫码登录」会在弹窗里直接显示二维码，用 B 站 App 扫码并在手机上确认即可；二维码过期后点一下刷新。登录后请求字幕和视频时带上你的登录状态，AI 字幕更全、清晰度更高、不容易被 B 站临时拦截。登录信息只加密保存在本机（不进设置、不进备份），只发给 B 站；同一行可以「退出」。B 站判定登录失效时会提示重新扫码。
- **新建链接条目**：首页「B 站链接」→ 贴链接 → 解析 → 选分 P 和字幕 → 「导入」。条目和其他音视频一样出现在列表和资源库里（带「B 站」标记），字幕可以搜索、点句跳转、提问、生成讲义（讲义只依据字幕，不截取画面）、制卡出题。同一个视频的同一 P 再导入一次，会更新原来那条的字幕，不会重复建条目。
- **整门课一次导入**：多 P 合集在弹窗里勾选要导入的分 P（可「全选」），点「导入 N 个分 P」。应用逐 P 拉取字幕、每 P 新建一个条目，弹窗里显示「正在导入 3/16」的进度，可以随时「停止」（做完当前这一 P 就停）。选中的字幕语言对每一 P 优先使用，某一 P 没有这条时按默认规则选。没有字幕的分 P 会自动跳过；结束后提示导入了几个、哪些分 P 跳过或失败。为避免被 B 站限流，每 P 之间会稍作间隔，100 P 大约一两分钟；如果中途被 B 站拦截，导入会停下并提示剩余几个，过几分钟再导入剩下的即可（已导入的不会重复）。
- **播放**：学习页里直接用应用自己的播放器播放（应用向 B 站要到视频地址后在本机转发，不保存视频文件），和本地视频一样可以拖动进度、截帧、字幕跟随高亮、记录观看进度。少数视频无法直接播放时会自动改用 B 站的播放器并提示，工具栏上可以在「改用 B 站播放器」和「重试应用内播放」之间切换；用 B 站播放器时不能截帧、不记进度。也可以点「在 B 站打开」去浏览器或 B 站 App 里看。
- **不能转写**：链接条目没有本地音视频，不能用语音识别转写；字幕不满意时可以「重新获取 B 站字幕」换一条，或导入自己的字幕文件。
- **给本地视频挂字幕**：已经下载到本地的 B 站视频，可以在行菜单或学习页「⋯」里选「从 B 站链接获取字幕…」，贴同一视频的链接，直接用 B 站的字幕，省去转写费用。
- **拿不到字幕时**：没有字幕的视频（UP 主没上传、B 站也没生成 AI 字幕，常见于纯音乐和很短的视频）会提示「没有可用字幕」，可以把视频下载到本地后导入并转写。暂不支持番剧 / 影视、课堂（付费课程）、音频和直播的链接。B 站偶尔会临时拦截频繁的请求，过几分钟再试即可。

## 时间戳与引用

- 字幕会自动进入检索，在任何对话里都能问到这节课的内容，AI 的回答会带 `▶ 01:23 · 文件名` 这样的时间戳引用。
- **点时间戳跳转**：在对话页里点，视频在对话右侧面板打开并跳到那一刻；在笔记（讲义的时间锚点）、闪卡出处等其他地方点，会打开「音视频」学习页并跳到那一刻。
- **截帧提问**：看到看不懂的板书或图表，点「截取当前帧」，画面会作为图片引用到对话里，接着提问即可。

## 进度与学习时长

- **断点续播**：每节课记住上次看到的位置，下次打开自动继续。
- **观看进度**：首页的进度条和「练习」标签里的统计显示看了多少、是否看完；「在看」筛选列出看了一部分的课。
- **学习时长**：应用在你使用时（窗口可见且有操作，或正在播放音视频）自动累计学习时长，可在「设置 → 数据统计」的学习热力图中切换到「时长」查看。

## 和资源库的关系

- **是同一份文件**：在「音视频」导入的文件就在资源库里，在资源库导入的音视频也会出现在「音视频」首页。可以把它移到课程文件夹里，和这门课的课件、笔记放在一起，「音视频」里照样能看到。
- **资源库照样能看**：在资源库里打开音视频，还是同一个学习视图（播放器、字幕、转写都在）；想用讲义、问答、练习的完整流程，点工具栏的「在音视频中学习」。
- **删除就是删除资源**：在「音视频」里删除，等于在资源库里删除这个文件，它会进入资源库的回收站，可以恢复。
- 引用到对话、知识库检索、备份与同步都和其他资料一样，详见 [资源库](/user-guide/learning-hub)。

## 📱 移动端说明

- **入口**：抽屉应用启动器里的「音视频」。
- **导入**：点页面底部的「导入音视频」，用系统文件选择器选择音频或视频（可多选），导入时显示进度条；手机上不能拖放。旁边的「B 站链接」可以直接贴 B 站 App 里复制的分享链接。
- **抽屉**：左侧抽屉上半部分是「最近在看」，点一下直接回到那节课。
- **学习页布局**：播放器固定在顶部（16:9），下面是「字幕 / 讲义 / 问答 / 练习」四个标签，默认显示字幕。
- **行菜单**：长按一行，或点行尾「⋯」，弹出操作菜单。
- **返回键**：先关闭弹出的菜单和弹层，再从学习页回到首页。
- **转写**：在前台进行；切到后台被系统暂停后，回到应用会接着转写，已完成的段不会丢。

## 常见问题

**Q1：导入或播放时提示格式不支持？**
Opus 编码的 WebM / OGG、AC-3 音轨等格式暂不支持，请先用格式转换工具转成 MP4（视频）或 M4A（音频）再导入。

**Q2：点「转写」提示未配置？**
转写需要语音识别模型。到「设置 → 模型服务」配好提供方的 API 密钥，再到「设置 → 模型分配」选择「语音识别（ASR）模型」（与语音输入共用）。不想付费转写的话，可以直接导入现成的字幕文件。

**Q3：文件很大，导入很慢？**
单个文件最大 4GB。导入时文件是边读边写入的，不会占满内存，但大文件仍需要一些时间，列表里会显示「导入中」。播放时同样按需分段读取，几个 GB 的视频也能直接在应用内播放和拖动。转写长课程同样耗时较长，可以先去做别的，转写在后台继续。

**Q4：转写到一半关了应用怎么办？**
已完成的段会保存，再次点「转写」从断点继续，不会重复计费已完成的部分。

**Q5：讲义能导出成 Word 吗？**
能。讲义保存为笔记，在笔记的导出菜单里导出 Word，可选「讲义 / 公文」版式。
