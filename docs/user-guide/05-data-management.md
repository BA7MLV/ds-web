# 备份与同步

## 概述

DeepStudent 的数据默认只保存在本机。本页介绍如何备份数据、在新设备上恢复，
以及如何配置多端云同步。

入口：**设置 → 数据治理**。

你的数据在磁盘上的默认位置：

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/com.deepstudent.app/` |
| Windows | `%APPDATA%\com.deepstudent.app\` |
| Linux | `~/.local/share/com.deepstudent.app/`（或对应 XDG 数据目录） |

> 请不要手动修改该目录下的文件；备份和迁移请使用下文的界面操作。

## 备份数据

### 理解备份层级

备份时可以选择包含哪些数据，层级越高包含越多、体积越大：

| 层级 | 名称 | 包含内容 | 建议 |
|------|------|---------|------|
| P0 | **核心数据** | 聊天记录、资料库结构、卡片与设置（chat_v2.db、vfs.db、主库） | 体积小，高频备份 |
| P1 | **重要数据** | P0 + 用量统计、笔记附件 | 每日备份 |
| P2 | **可重建数据** | P0-P1 + 向量索引（丢失后可通过重新索引恢复） | 按需备份 |
| P3 | **大型资产** | P0-P2 + 图片/文档/视频等媒体文件 | 定期导出或增量备份 |

### 操作步骤

1. 打开 **设置 → 数据治理 → 备份**。
2. 勾选「**使用分层备份**」并选择层级（不勾选则备份全部数据）；
   或使用「**完整备份**」/「**增量备份**」快捷按钮。
3. 点击「**导出备份**」，生成 ZIP 文件保存到你选择的位置。

备份列表中的每个备份支持 **验证**（检查完整性）、**导出**、**恢复**、**删除**。
若上次备份中断，页面会提示「有未完成的备份任务」，可点击恢复继续。

建议开启自动备份：设置备份频率（如每 24 小时）和保留策略（如保留最近 7 天）。

## 恢复数据

1. 打开 **设置 → 数据治理 → 备份**。
2. 在备份列表中选择一个备份点击「**恢复**」，或点击「**从 ZIP 导入**」选择备份文件。
3. 恢复完成后按提示重启应用（「数据恢复完成，建议重启应用以确保数据一致性」）。

两个安全机制，不用担心误操作：

- 恢复前系统会自动创建「**预恢复备份**」，随时可以回到恢复前的状态。
- 应用采用**双数据空间**设计：导入的备份先写入备用空间，重启后才切换生效，
  原数据空间保持完整。

## 云同步（实验性）

支持基于 WebDAV（如坚果云）或 S3 兼容存储（如 AWS S3、MinIO、阿里云 OSS）
的私有云同步，实现多端数据互通。

### 配置

1. 打开 **设置 → 数据治理 → 同步**。
2. 填写你的 WebDAV 或 S3 服务地址与凭据。
3. 选择同步方式：**双向同步** / 仅**上传** / 仅**下载**。

### 处理冲突

多端同时修改同一数据时会触发冲突检测，可选解决策略：

- **保留最新**：按时间戳自动选较新的数据（推荐）
- **保留本地**：以当前设备为准
- **使用云端**：以云端数据覆盖本地
- **手动处理**：暂不处理，稍后逐条解决

无法自动合并的记录会进入「**同步隔离区**」，可逐条 **重试** 或 **丢弃**。

> 云同步为实验性功能，建议同步前先做一次完整备份。

## 迁移到新设备

1. 旧设备：**数据治理 → 备份** → 分层备份（建议 P3 全量）→ 导出 ZIP。
2. 把 ZIP 文件拷贝到新设备（U 盘、网盘均可）。
3. 新设备：安装 DeepStudent → **数据治理 → 备份 → 从 ZIP 导入** → 按提示重启。
4. API 密钥需要在新设备上重新配置（密钥绑定本机加密，不随备份明文迁移时请重新填写确认）。

### 从旧版本升级

从旧版本升级时，应用会在启动时自动检测并执行数据结构升级，如有提示请重启应用。
旧版「错题本」数据已升级为「题目集」。若升级后数据异常，可在
**数据治理 → 审计** 查看迁移日志，或联系支持。

## 健康检查、审计与缓存

- **健康检查**：在「概览」子页点击「**运行健康检查**」，扫描数据库完整性与索引状态，
  发现问题时提供修复建议。
- **审计日志**：「审计」子页记录所有备份、恢复、同步、迁移操作，可按类型和状态筛选。
- **缓存管理**：「缓存」子页可清理 PDF 渲染缓存、图片缓存等，释放磁盘空间。

## 常见问题

**Q：备份文件占用太多空间怎么办？**

避免对 P2/P3 层级过于频繁地全量备份；删除旧备份文件；用「清理」功能移除未引用的缓存。

**Q：同步时提示冲突怎么办？**

属正常现象。点击「解决冲突」后通常选「保留最新」即可；确定某台设备的修改更重要时
选「保留本地」或「使用云端」。

**Q：恢复备份后数据不对怎么办？**

在备份列表中找到系统自动创建的「预恢复备份」并恢复，即可回到恢复操作之前的状态。
