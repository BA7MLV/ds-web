# 学习桌面

> 桌面端的默认界面：应用和资料都在窗口里打开，可以并排摆放、平铺对照。底部 Dock 打开应用，顶部状态栏提醒今天要复习的卡片、进行中的制卡任务和番茄钟。

## 功能概览

- **默认开启**：Windows、macOS、Linux 桌面端安装后直接进入学习桌面。Android 没有学习桌面，用的是抽屉导航（见 [移动端指南](/user-guide/mobile)）。
- **一切皆窗口**：对话、资源库、待办、闪卡、设置是应用窗口；每份教材、笔记、题目集也各开一个窗口。同一个应用可以开多个窗口，比如两个会话并排对比。
- **随时可以退回经典布局**：不习惯窗口化，就切回「左侧导航 + 单个页面」的传统布局，桌面上的窗口布局会保留，下次切回来还在。

## 界面组成

| 区域 | 位置 | 作用 |
|---|---|---|
| 状态栏 | 屏幕顶部 | 学习桌面菜单、搜索、设置、今日节律 |
| 桌面 | 中间 | 窗口摆放区；壁纸上可以显示日历与学习日程 |
| Dock | 屏幕底部 | 打开常用应用，查看哪些应用正在运行 |

### 状态栏

- **DeepStudent 图标**（最左边）：打开学习桌面菜单，可以「重命名桌面…」「系统设置…」「退出学习桌面」。
- **搜索**：打开「全部应用」，按 `⌘K`（Windows / Linux 为 `Ctrl+K`）也可以。
- **齿轮**：打开设置。
- **今日节律**：汇总今日到期的闪卡、进行中的制卡任务、番茄钟专注状态和定时任务。点开能看到详情，并直接跳到对应应用。

### Dock

默认固定四个应用：「对话」「资源库」「设置」「待办」；最右边是「全部应用」。正在运行的应用下方有标记。

在 Dock 图标上右键，可以「新建窗口」「显示全部窗口」「关闭全部窗口」，或「固定到 Dock」「从 Dock 移除」。常用的应用（比如「闪卡」）固定上去，下次一点就开。

### 全部应用

点 Dock 最右边的「全部应用」或按 `⌘K` / `Ctrl+K` 打开。可以搜索**应用、命令、资源和聊天记录**，`↑` / `↓` 选择、`Enter` 打开、`Esc` 关闭，也可以在网格和列表视图之间切换。

常用应用：对话、资源库、待办、闪卡、Anki制卡、模板管理、技能管理、番茄钟、设置；在「设置 → 学习桌面」开启「内置浏览器」后，还会多一个浏览器。

## 核心操作

### 第一次打开

桌面中间会显示「你的学习桌面」卡片，里面有几个快速入口：「新建对话」「打开资源库」「查看待办」「闪卡」「全部应用」。第一次还会弹出四步引导（Dock 应用 → 快速搜索 → 状态栏节律 → Agent 控制），之后可以在桌面右键菜单里「重新查看引导」。

关闭应用时桌面状态会自动保存。再次启动时，空桌面上会出现「恢复上次桌面（N 个窗口）」按钮，点一下就能把上次的窗口全部重新打开。想每次启动都自动恢复，到「设置 → 学习桌面」开启「启动时自动恢复上次桌面」（默认关闭，这样启动更快）。

### 打开应用和资料

- **应用**：点 Dock 图标，或在「全部应用」里搜索。
- **资料**：在「资源库」里双击，教材、题目集、翻译、作文、图片、文件会各自开成窗口；笔记和知识导图在笔记窗口里打开。
- **会话**：在「对话」窗口的会话列表里，点会话右侧的「…」→「在新窗口打开」，就能把两个会话并排放着对比。

### 摆放窗口

- **移动和缩放**：拖动标题栏移动窗口，拖动窗口边缘调整大小。
- **拖到边缘平铺**：把窗口拖到屏幕左边或右边松手，占半屏；拖到四个角，占四分之一；拖到顶部，填满桌面；拖到底边中间，占下半屏。拖动时按住 `⌥`（Windows / Linux 为 `Alt`），感应区会变大，不用贴死边缘；按住 `⌥` 拖到顶部则变成上半屏。
- **标题栏三个圆点**：红色关闭，黄色最小化，绿色在「填满桌面」和「原尺寸」之间切换。鼠标停在绿点上会弹出平铺选项（左右半屏、四个角、填满、居中、进入沉浸模式）。按住 `⌥` / `Alt` 再点红点或黄点，会关闭或最小化这个应用的全部窗口。
- **双击标题栏**：默认是缩放，可以在「设置 → 学习桌面」改成最小化或无操作。
- **沉浸模式**：窗口填满桌面，状态栏和 Dock 自动收起（鼠标移到屏幕边缘时滑出），适合专心读书；按 `Esc` 或再点一次绿点退出。
- **一键整理**：在桌面空白处右键，可以「平铺全部窗口」「窗口俯瞰」「显示桌面」「恢复窗口」。

### 切换窗口

- **窗口切换器**：按住 `Ctrl` 再按 `Tab` 循环选择，松开即切换。
- **窗口俯瞰**：所有打开的窗口平铺展示，点一个即聚焦，`Esc` 退出。
- **显示桌面**：最小化全部窗口，再按一次恢复。

### 常用快捷键

下表是 Windows / Linux 的写法；macOS 上把 `Ctrl` 换成 `⌘`、`Alt` 换成 `⌥`（例如 `Ctrl+Alt+←` 是 `⌘⌥←`）。在桌面上按 `?` 可以随时打开完整的快捷键速查表，显示的就是你这台电脑上的按键。

| 操作 | 快捷键 |
|---|---|
| 搜索应用与命令 | `Ctrl+K` |
| 平铺到左 / 右半屏 | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| 填满桌面 / 恢复原尺寸或最小化 | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| 居中窗口 | `Ctrl+Alt+C` |
| 窗口俯瞰 | `Ctrl+Alt+E` |
| 显示桌面 | `Ctrl+Alt+D` |
| 关闭当前窗口 | `Ctrl+W` |
| 关闭所有窗口 | `Ctrl+Alt+Shift+W` |
| 快捷键速查表 | `?` |

### 退出学习桌面

点状态栏最左边的 DeepStudent 图标 →「退出学习桌面」，或在「设置 → 学习桌面」关掉「学习桌面（默认）」开关，就会回到经典布局。如果有窗口里的内容还没保存，会取消退出并提示你先保存或关闭这些窗口，不会丢内容。想回来时，在「设置 → 学习桌面」重新打开开关即可。

## 进阶用法

### 让 AI 帮你操作桌面

在对话里让 AI 整理资料、推进学习时，它可以在已授权的学习应用里定位内容并执行操作。「设置 → 学习桌面 → AI 助手操控」决定它能做多少：

- **跟随**（默认）：AI 操作时自动打开目标窗口并带到前台，你能看着它一步步操作。
- **后台**：AI 照样操作，但不抢焦点，完成后在 Dock 上提示。
- **关闭**：AI 只能查看有哪些窗口，不会打开、关闭或操作窗口；需要改数据时直接在后台完成。

「操控演出节奏」可以选快速、正常或演示（放慢，便于讲解）。删除之类的破坏性操作，任何模式下都会先请求你确认。

### 外观与性能

在「设置 → 学习桌面」里还可以调整：

- **性能档位**：画质 / 均衡 / 性能，一键平衡画面效果和流畅度；电脑较旧时选「性能」。
- **视觉材质**：玻璃效果的强弱，可选跟随平台、全效果、降透明、极简。
- **Dock 大小**、**自动隐藏 Dock**、**自动隐藏菜单栏**、**平铺间距**。
- **桌面壁纸**：内置风景和渐变，也可以用自己的图片。
- **显示桌面组件**：在桌面上显示日历与今日日程；窗口较窄时可以关掉，腾出空间（桌面右键菜单里也能切换）。

为了省内存，暂时不用的后台窗口可能会自动休眠，点一下即可唤醒；有未保存内容的窗口不会被休眠。

## 📱 移动端说明

Android 版没有学习桌面，设置里也不显示这一项。移动端的导航方式见 [移动端指南](/user-guide/mobile)。

## 常见问题

**Q：打开应用后只看到一张空桌面，左边的导航栏去哪了？**
A：这是学习桌面，应用都在底部 Dock 和「全部应用」里。想要原来的左侧导航，点状态栏最左边的 DeepStudent 图标 →「退出学习桌面」。

**Q：窗口太多找不到了？**
A：按 `Ctrl+Alt+E`（macOS `⌘⌥E`）进入窗口俯瞰，或在桌面右键选「平铺全部窗口」。

**Q：窗口里显示「窗口已休眠」？**
A：这是为节省内存暂停了暂时不用的后台窗口，内容没有丢，点一下就会恢复。

**Q：电脑风扇响、拖窗口有点卡？**
A：到「设置 → 学习桌面」把「性能档位」切到「性能」，或把「视觉材质」改成「极简」。
