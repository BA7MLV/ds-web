# 模型与供应商配置

> 为 Deep Student 接入你自己的 AI 模型：保存一把 API 密钥，再告诉应用「哪个功能用哪个模型」，所有 AI 能力就都能用了。

## 功能概览

Deep Student 本身不内置任何「免费云端 AI」，所有 AI 功能都通过你自己配置的模型服务运行。相关设置在「设置 → 模型与 AI」分类下：

- **模型服务**：管理供应商和模型。应用预置了 13 家供应商：SiliconFlow（硅基流动）、DeepSeek、通义千问、智谱AI、字节豆包、MiniMax、月之暗面、OpenAI、Codex、Anthropic、NVIDIA、Xiaomi MiMo、Google Gemini。大多数只要保存 API 密钥就能用；也可以自建供应商，接入 xAI (Grok)、OpenRouter、Ollama 等任意兼容接口。
- **模型分配**：为不同功能指定不同模型。对话、Anki 制卡、题库批改与出题、翻译、嵌入、重排序、OCR、语音输入等各有独立的槽位，可以「对话用大模型、杂活用便宜的小模型」。

API 密钥只保存在本机，并且加密存储，不会上传到任何 Deep Student 服务器。

## 入口与界面布局

1. 打开「设置」：学习桌面里点 Dock 的「设置」或状态栏的齿轮图标；传统布局点左侧导航底部的「设置」。
2. 设置页左侧按六个分类组织：模型与 AI、应用体验、输入与个性化、工具与扩展、工作流与文档、数据与系统。在「模型与 AI」下选「模型服务」或「模型分配」。
3. 找不到某个设置时，用导航顶部的**设置搜索**（学习桌面的设置窗口里按 `⌘F` / `Ctrl+F` 直接聚焦）：输入关键词（如「温度」「嵌入」）就能跨分类搜索，`↑` / `↓` 选择、`Enter` 跳转，应用会切到对应页面并短暂高亮该设置项；`Esc` 清空搜索。

「模型服务」页为左右两栏：

- 左侧是**供应商列表**，每家供应商前有图标，灰色表示还没配密钥。桌面端可以拖动排序。
- 右侧是选中供应商的详情。顶部是名称和「访问官网」按钮（↗ 图标），SiliconFlow 带「推荐」标记；下面是连接信息（接口地址、API 密钥）和这家供应商的**模型列表**。官方 DeepSeek 还会显示账户余额。

「模型分配」页按用途分组排列，每一行对应一个功能，从下拉框选模型即可，选完自动保存。

## 核心操作

### 为预置供应商保存 API 密钥

1. 打开「设置 → 模型服务」，在左侧选择一家供应商（例如 DeepSeek 或 SiliconFlow）。
2. 点名称旁的「访问官网」，去供应商官网注册并创建 API 密钥。
3. 回到应用，把密钥粘贴进「API 密钥」输入框，点「**保存 API 密钥**」。只粘贴不保存时会提示「已粘贴，保存后才会使用」；保存成功后显示「已安全保存，下次无需重新输入」。
4. 建议随后在模型行上点「测试连接」，确认密钥可用。

还没配置过的供应商会直接展开接口地址和密钥输入框；已经配置过的，连接信息会收成一行（显示接口地址和「已配置 API 密钥」），点它展开就能修改或「清除」密钥。

预置供应商已经填好正确的接口地址，一般不用改。供应商本身不能删除，但其中的模型配置可以自由编辑和删除。

### 从接口获取模型列表

供应商开放了新模型，或者预置列表里没有你想用的模型：

1. 在供应商详情里点「获取模型列表」，模型列表上方会展开选择面板。
2. 搜索并勾选需要的模型（已添加过的标着「已添加」），也可以「全选新模型」。
3. 点「添加 N 个模型」。如果接口返回了上下文窗口和最大输出长度，会一并填好。

### 手动添加模型

1. 在供应商详情里点「添加模型」。
2. 填写模型名称，必须和调用接口时用的真实模型名一致。
3. 在「能力」标签页勾选模型能力：多模态模型（支持图片）、推理模型、嵌入模型、重排序模型、生图模型、支持工具调用。能力决定了这个模型会出现在哪些分配槽位里。
4. 需要时在「参数」「推理」标签页调整温度、最大输出 Token、思维链等参数，然后保存。

### 添加自定义供应商（Grok / OpenRouter / Ollama 等）

1. 在供应商列表上方点「添加供应商」（＋号）。
2. 填写供应商名称，选择「供应商类型」：除预置的几家外，还有 xAI (Grok)、百度文心、Mistral、OpenRouter、Ollama、通用适配器和自定义。
3. 选择「API 协议」：OpenAI Chat Completions、OpenAI Responses、Google GenerateContent、Anthropic Messages。
4. 填写「接口地址」和「API 密钥」。如果是本机自建的服务（Ollama / vLLM / llama.cpp 等），勾选「无需 API Key」，保存后会自动获取模型列表。
5. 需要时还可以填：「备用 API 密钥」（每行一把，主密钥失效时按顺序切换）、「最大输出 Token 上限」、「发现/测试超时（毫秒）」，以及 JSON 格式的「自定义请求头」。

### 用 ChatGPT 账号登录 Codex

预置的「Codex」供应商不用 API 密钥，而是直接登录 ChatGPT 账号，使用账号套餐里的 Codex 额度：

1. 在供应商列表选择「Codex」。
2. 点「使用浏览器登录」（或「使用设备码登录」），在浏览器里完成 ChatGPT 授权。
3. 登录后能看到套餐信息和「Codex 额度」用量，可以随时「刷新额度」或「退出登录」。

### 为各功能分配模型

打开「设置 → 模型分配」，页面分成几组：

| 分组 | 槽位 | 说明 |
|---|---|---|
| 基础核心模型 | 对话模型（解答 + 对话） | **必配**，所有 AI 对话的基础 |
| 功能增强模型 | Anki制卡模型、题库AI批改模型、题库AI出题模型、标题/标签生成模型、翻译专用模型、记忆决策模型、上下文压缩模型、生图模型 | 不配置时，多数会改用对话模型 |
| 语音识别 | 语音识别（ASR）模型 | 语音输入、音视频转写（字幕、检索、讲义） |
| RAG 与知识库 | 重排序模型、多模态重排序模型，以及「嵌入维度管理」 | 让 AI 能检索你的资料库 |
| OCR 引擎 | 可以添加多个，按优先级自动切换 | 识别图片和扫描件里的文字 |

每个下拉框选完自动保存。页面底部的「配置检查」会列出各项是否已配置。

「上下文压缩模型」用于长对话快到上下文上限时生成摘要，建议选便宜、上下文长的模型；「聊天翻译显示模式」决定对话里的翻译怎么显示。

### 配置嵌入模型（嵌入维度管理）

要让 AI 检索你导入的资料（知识库问答），必须有一个默认的嵌入维度，并为它关联一个嵌入模型：

1. 先在「模型服务」里添加一个嵌入模型（能力勾选「嵌入模型」），例如 `BAAI/bge-m3`。
2. 在「模型分配 → 嵌入维度管理」里点「新建维度」（或用「常用维度」快捷创建），填写维度值，例如 bge-m3 是 1024。
3. 为这个维度分配刚才的嵌入模型，再点「设为默认」。

之后导入的资料会用这个模型建索引。表格里能看到每个维度的关联模型、数据量和状态。删除维度会同时清掉它的向量数据，需要重新建索引。

### 硅基流动一键分配

只有一把 SiliconFlow（硅基流动）密钥、想最快把所有功能跑起来：

1. 在「模型服务」里选择 SiliconFlow，粘贴密钥后点「保存 API 密钥」。
2. 点旁边的「**一键分配**」。

应用会创建并分配一整套模型：对话、题库批改与题目解析用 DeepSeek-V3.2，Anki 制卡用 Qwen3-30B，嵌入用 bge-m3（自动建好 1024 维并设为默认），重排序用 bge-reranker-v2-m3，翻译用 Hunyuan-MT-7B，标题生成和记忆决策用 Ling-mini-2.0，语音识别用 TeleSpeechASR；OCR 按优先级配好 PaddleOCR-VL-1.5、PaddleOCR-VL、DeepSeek-OCR、Qwen3-VL-8B 四个引擎。之后可以在「模型分配」里逐项替换。

## 进阶用法

### 推理 / 思维链参数

编辑模型时，「推理」标签页可以统一设置思维链行为（如 OpenAI 的 reasoning effort、Claude 的扩展思考、Gemini 的 thinking budget），应用会自动转换成对应平台的参数格式。DeepSeek、通义千问、豆包、Kimi、智谱等国产模型也有各自的思考开关，界面会按所选供应商显示对应选项。

### 参数与上下文

「最大输出 Token」「上下文窗口大小」「温度参数」等在模型编辑对话框的「参数」标签页调整。上下文窗口留空时，会根据模型名称自动推断。

## 📱 移动端说明

- 从抽屉菜单进入「设置」。设置是两级页面：先在首页选分区，再进入具体设置，功能与桌面端一致。
- 「模型服务」在小屏上也是两级：先看供应商列表，点某一行进入详情；「访问官网」按钮在顶栏右侧。
- 供应商列表在触屏上**不能拖动排序**。
- Codex 的浏览器登录在移动端可能受系统限制，遇到问题可以改用「使用设备码登录」。

## 常见问题

**Q：填了密钥还是发不出消息？**
A：先确认点过「保存 API 密钥」；再确认「模型分配」里的「对话模型」已经选好；最后回到「模型服务」对这个模型点「测试连接」。连接失败时，依次检查接口地址、密钥和模型名称。

**Q：资料导入了，AI 却说检索不到？**
A：多半是没配嵌入模型。打开「模型分配 → 嵌入维度管理」，确认有默认维度且已关联嵌入模型，然后回资源库检查「知识库索引」里资料是否已经「已索引」。

**Q：预置供应商可以删除吗？**
A：不能，内置供应商入口不可删除（避免误删模板），不填密钥让它闲置即可；供应商下的模型配置可以自由删除。自建供应商删除时，其下所有模型会一并移除。

**Q：一个功能不分配模型会怎样？**
A：多数可选槽位会自动回退：翻译、标题生成、上下文压缩等不配置时用对话模型；重排序模型不配置就跳过重排。只有「对话模型」，以及（要用知识库时）嵌入模型是必须配的。

**Q：API 密钥存在哪里？安全吗？**
A：密钥只保存在本机，用 AES-256-GCM 加密存储，应用不会把密钥上传给任何第三方。注意：使用 AI 功能时，对话内容会发送给你配置的模型服务商，受对方隐私政策约束。

**Q：想用本地模型（不联网）怎么办？**
A：先在本机部署 Ollama / vLLM / llama.cpp 等服务，然后「添加供应商」→ 类型选 Ollama（或通用适配器）→ 填本机接口地址（Ollama 一般是 `http://localhost:11434/v1`）→ 勾选「无需 API Key」。保存后会自动拉取本机已有的模型。

**Q：删除一个正在被使用的模型配置会怎样？**
A：如果它还被某些功能使用，删除时会提示「该配置仍被 N 个功能使用」；继续删除会清空这些分配，相关功能需要重新选模型。
