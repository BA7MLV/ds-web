# 待办与番茄钟

## 概述

待办是 DeepStudent 内置的任务管理工具，配合番茄钟帮你保持学习节奏。

入口：点击侧边栏的「**待办**」。学习资源中也可以「新建待办列表」，
作为资料的一部分管理。

---

## 添加与管理待办

### 快速添加

在顶部输入框输入内容后回车即可。支持快捷语法，例如输入
「明天交作业 !高」会自动识别出截止日期「明天」和优先级「高」。

### 待办属性

点击任意待办打开详情面板，可设置：

| 属性 | 说明 |
|------|------|
| 优先级 | 无 / 低 / 中 / 高 / 紧急 |
| 截止日期与时间 | 到期前后自动进入「今日」「已过期」视图 |
| 提醒 | 到点发送系统通知 |
| 重复 | 每天 / 工作日 / 每周 / 每月 / 每年 / 自定义间隔 |
| 番茄 | 预估完成所需的番茄数 |
| 标签 | 自由添加标签 |
| 子任务 | 手动添加，或点击「**AI 拆解**」让 AI 拆成可执行的子任务 |

### 智能视图与列表

左侧提供智能视图：**收件箱**、**今日**、**即将到期**、**四象限**（按重要/紧急分类）、
**已过期**、**已完成**。也可以「**新建列表**」按科目或项目分类管理。

### 回收站

删除的列表和待办会先进入回收站，可恢复或彻底删除。逾期待办会通过系统通知提醒
（通知策略在 **设置 → 常规** 中调整）。

## 番茄钟

### 开始专注

1. 在待办上点击「**开始专注**」，或直接点击番茄钟挂件。
2. 默认专注 25 分钟，随后进入短休息；累计若干个番茄后进入长休息。
3. 专注期间可 **暂停** / **继续** / **停止**，或「**跳过休息**」。

### 沉浸模式与白噪声

- 点击「**进入沉浸式专注模式**」全屏专注，按 `Esc` 退出，`Space` 暂停/恢复。
- 「**开启环境音**」提供海浪、细雨、白噪、雨声四种音色，可调音量。
- 「**弹出置顶小窗**」把计时器固定在屏幕角落（桌面端）。

### 番茄钟设置

点击番茄钟面板中的设置图标，可调整：

- 专注时长、短休息、长休息时长与长休息间隔
- 自动开始休息 / 休息后自动开始专注
- **严格模式**：专注期间不可暂停
- **正计时**：改为秒表向上计时
- 结束前提醒、每日目标

### 专注统计

番茄钟面板展示今日番茄数、专注分钟数与今日目标进度；
「**专注趋势**」弹窗提供热力图、日均番茄数和周环比。
每条待办的详情中也能看到它的「专注历史」。

## 与 AI 协作

在对话中激活「个人待办」工具组技能（`user-todo-tools`）后，可以直接对 AI 说：

- 「帮我添加待办：周五前交物理实验报告，优先级高」
- 「我今天有什么任务？」
- 「把复习计划拆成待办清单」

AI 会直接读写你的真实待办列表。
