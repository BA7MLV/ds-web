# 深度调研与智能记忆

> 让 AI 像研究助理一样多步骤地完成调研并写成报告，同时在长期使用中自动记住你的偏好与学习状态。

## 功能概览

**深度调研（调研模式）**是一个内置的多步骤调研助手。你给出一个调研主题，AI 会：先向你确认调研深度与输出格式偏好，然后把任务拆解成清单，联网搜索、检索你的本地资料库、交叉验证信息，最后把结构化的调研报告直接写进你的笔记库。适合技术调研、课题综述前的资料收集、时事与趋势梳理等场景。

**智能记忆**让 AI 越用越懂你。开启后，AI 会在对话结束后自动提取关于你的信息（身份、偏好、学习目标、学科状态等），保存为可查看、可编辑的记忆条目；之后的对话会自动检索并注入相关记忆，让回答更贴合你的情况。所有记忆以笔记形式存储在本地，你随时可以浏览、修改、删除或导出。

## 入口与界面布局

### 深度调研

调研模式是一项内置技能，在对话页面激活，有两种方式：

- **斜杠命令**：在输入框开头输入 `/`，从弹出的「技能命令」列表中选择「调研模式」（`/research-mode`）。
- **技能面板**：点击输入栏加号菜单（「添加与会话选项」）→「技能」，在技能列表中搜索并「激活」调研模式；面板中会显示「已激活」标记。

调研进行时，消息区会依次出现这些界面元素：

- **提问卡片**：AI 用来向你确认偏好，带选项按钮（含「推荐」标记）、「确认选择」和自定义回答输入框，可「忽略」。
- **任务列表**：显示"N 个任务完成 / 执行中"的进度清单，右侧任务面板也会同步展示「计划」步骤。
- **网络搜索 / 文档知识库检索块**：显示每次搜索的结果条数，可展开查看来源。
- **笔记写入块**：报告写入笔记时显示「创建笔记」「追加内容」等操作，点「在学习资源中打开」可直接在资源库里查看报告。

### 智能记忆

记忆相关界面分布在三处：

- **设置 → 记忆**：功能总开关、存储位置与自动提取频率。
- **资源库 → 左侧「AI 记忆」**：「记忆管理」页面，浏览、搜索、编辑全部记忆，并可查看画像与记忆树。
- **对话消息中**：当 AI 检索到相关记忆时，回答上方会出现「用户记忆」块，显示命中的记忆条数与类型。

## 核心操作

### 发起一次深度调研

1. 新建一个会话（建议每次调研单开会话，避免上下文过长）。
2. 输入 `/` 并选择「调研模式」，然后在同一条消息里写清调研主题，例如：`/research-mode 调研 2026 年大语言模型的最新发展趋势`，发送。
3. AI 会先弹出提问卡片，询问调研深度（快速概览 / 中等深度 / 深度调研）和输出格式偏好，点选后按「确认选择」（也可以直接输入自定义回答）。
4. AI 随后创建任务清单并逐步执行：联网搜索、本地知识库检索、整理分析。你可以随时观察任务列表和搜索块的进度，也可以点「停止」中断。
5. 调研结束后，报告会保存为一篇笔记，包含固定结构：调研概述、主要发现、详细分析、结论与建议、参考来源。在笔记写入块中点「在学习资源中打开」即可阅读，后续可在 [笔记](/user-guide/notes) 中继续编辑。

提示：调研会执行较多次工具调用，如果中途出现「已达工具调用限制」卡片，点「继续执行」即可让 AI 接着做完。

### 跟踪调研进度

1. 调研开始后，消息区的任务列表会实时更新（如"3 / 7 个任务完成"），全部完成时显示「所有任务已完成」。
2. 桌面端右侧的任务面板同步展示「计划」步骤、「近期活动」和「产物」；报告笔记会出现在产物列表中，可直接「预览」。
3. 每个搜索块都可展开核对来源，来源类型会标注为「网络搜索」「文档知识库」「用户记忆」或「学术论文」，点「打开来源」可跳转原文。
4. 对调研方向不满意时，随时点「停止」，补充一条新的指示再让 AI 继续；AI 会用「任务列表」调整后续步骤。

### 调研前的准备：配置搜索引擎

深度调研依赖联网搜索。请先前往「设置 → 外部搜索」：

1. 从支持的 8 个引擎中选择一个：默认选中的「Bing RSS（免费）」无需任何 Key，可直接使用；效果更好的引擎需填入对应凭据——Google CSE、SerpAPI、Tavily、Brave、智谱、博查填 API Key，SearXNG 填自建实例的端点地址。
2. 用「测试可用性」按钮验证连通性，并设置「默认搜索引擎」。
3. 如果检索本地资料，需要相关文档已在资源库的「知识库索引」里完成索引（见 [资源库](/user-guide/learning-hub)）。

### 开启智能记忆

1. 打开「设置 → 记忆」（在「输入与个性化」分类下）。
2. 打开「启用」开关。开启后 AI 会自动提取并调用关于你的信息来个性化对话体验；关闭后不再提取、检索或注入任何用户记忆。
3. 在「存储位置」中选择或新建一个文件夹作为记忆根目录（默认名称「我的记忆」）。记忆以普通笔记形式存放在这个文件夹里。
4. 按需调整：
   - 「自动创建子文件夹」：写入记忆时自动按分类建子文件夹
   - 「默认分类」：未指定分类时记忆存入的子文件夹（通用 / 偏好 / 经历）
   - 「自动提取频率」：对话结束后自动提取记忆的频率，可选「关闭 / 平衡 / 积极」
5. （可选）在「设置 → 模型分配」中指定「记忆决策模型」——用于判断新记忆应当新增、更新还是合并，建议选择快速轻量的模型；不设置时使用功能增强模型。

### 查看与管理记忆

1. 打开资源库，在左侧点「AI 记忆」进入「记忆管理」页面（首次进入若未设置根文件夹，会引导你「选择记忆根文件夹」或「创建记忆文件夹」）。
2. 顶部搜索框可按关键词「搜索记忆...」。
3. 点击任意记忆可「编辑记忆」，修改标题与内容；也可以手动「创建新记忆」。
4. 勾选多条记忆可批量删除（有确认弹窗）；单条删除同样需要确认。
5. 点「导出记忆」可把全部记忆导出保存。
6. 页面还提供「记忆树」视图（按分类的树状结构）和用户画像展示；画像由系统在积累足够记忆后自动汇总生成。

### 在对话中利用记忆

1. 记忆开启后无需额外操作：提问时 AI 会自动检索相关记忆，回答上方出现「用户记忆」块，标注命中条数和类型。记忆分三类：
   - **对话记忆**：从近期对话中提取的短期上下文
   - **长期记忆**：稳定的事实与偏好（如"目标院校""薄弱科目"）
   - **用户画像**：由多条记忆汇总生成的整体描述
2. 展开记忆块可查看具体命中了哪几条，点击可跳转到对应记忆。
3. 你也可以直接让 AI 记住某件事，例如发送"记住：我是高三学生，目标院校是××"，AI 会调用记忆工具写入（写入类操作受当前会话权限档位约束，见 [AI 对话与会话管理](/user-guide/chat) 中的"问一问 / 想一想 / 做一做"）。

## 进阶用法

- **调研 + 记忆联动**：调研模式可以按需加载记忆工具，让 AI 在调研时参考你已有的背景（如研究方向），并把重要结论存为长期记忆。
- **在课题中固定调研配置**：把调研模式设为某个课题（分组）的「默认技能」，该课题下每个新会话自动带调研能力，配合「分组 System Prompt」可以固定报告风格。
- **控制调研的权限**：调研主要是搜索与写笔记。若想在写报告前先过目，把会话切到「想一想」档位，AI 每次写入前都会请你「确认执行计划」。
- **记忆的自动维护**：新提取的事实会与已有记忆做语义比对，由 AI 判定是新增、更新、追加还是删除，避免重复堆积；长期未被命中的记忆条目会逐渐淡出摘要，高频命中的条目会被突出。

## 📱 移动端说明

- **深度调研**：移动端可正常使用。在对话输入框输入 `/` 选择调研模式即可；任务列表、搜索块、提问卡片均适配小屏。建议调研期间保持应用在前台，切走后台可能中断长时间的生成。
- **记忆管理**：打开资源库，点左上角 ☰ 打开抽屉，选择「AI 记忆」。未设置根文件夹时显示引导页；已设置时可浏览记忆列表与树状图。编辑、删除操作与桌面端一致。
- **记忆设置**：移动端从任意页面抽屉底部进入「设置」，在分组列表中点「常规」，找到「记忆」区块即可配置开关、存储位置与提取频率。
- **搜索引擎配置**：同样在移动端设置的「外部搜索」分区中完成，与桌面端一致。

## 常见问题

**Q1：发起调研后 AI 说搜索失败 / 没有联网结果？**
大概率是还没配置搜索引擎。前往「设置 → 外部搜索」选择一个引擎（Bing RSS 免费可直接用，其余需填 API Key）并设为默认，用「测试可用性」按钮确认可用后重试。

**Q2：调研报告保存在哪里？**
报告以笔记形式保存在你的笔记库中，调研结束时消息里的笔记块会给出入口（「在学习资源中打开」）；之后也可以随时在资源库中找到并继续编辑（见 [资源库](/user-guide/learning-hub)）。

**Q3：调研做到一半停下来了？**
两种常见情况：一是触发了工具调用上限，消息区会出现「已达工具调用限制」卡片，点「继续执行」或直接发送"继续"即可；二是 AI 的写操作在等你审批，查看是否有待确认的计划或工具确认卡片。

**Q4：AI 记住了过时或错误的信息怎么办？**
到资源库「AI 记忆」的「记忆管理」里搜索到对应条目，直接编辑修正或删除即可；AI 下次对话会使用更新后的记忆。

**Q5：我不想让 AI 记录我的信息，怎么彻底关掉？**
在「设置 → 记忆」关闭「启用」开关即可，关闭后不再提取、检索或注入用户记忆。已有的记忆条目不会被自动删除，可在「记忆管理」中自行批量删除；也可以把「自动提取频率」设为「关闭」，保留手动记忆但停止对话后的自动提取（已有记忆的整理和画像更新仍照常进行）。

**Q6：记忆数据存在哪里？会上传云端吗？**
记忆以笔记文件形式存储在本地你指定的记忆根文件夹中，不会单独上传。只有在你主动使用云同步备份时才会随其他数据一起备份，见 [数据管理与云同步](/user-guide/data-sync)。
