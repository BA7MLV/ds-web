# 什么是 DeepStudent

![主图](/img/example/软件主页图-1280.webp)

::: tip 一句话介绍
DeepStudent 是一款免费开源的 AI 学习工作台：把资料问答、笔记、知识导图、刷题、翻译、
作文批改和 Anki 制卡放进同一个应用，数据默认保存在你自己的电脑上。
:::

## 它能帮你做什么

- **和资料对话**：导入 PDF、教材、笔记后直接向 AI 提问，回答附带出处页码。
- **整理知识**：Markdown 笔记、知识导图（含背诵挖空模式）、AI 长期记忆。
- **刷题与复盘**：拍照识别试卷、自动拆题、错题优先练习、模考与知识点统计。
- **语言学习**：翻译工作台（术语表、逐段对照）、AI 作文批改（多轮迭代）。
- **高效复习**：对话中一句话生成 Anki 卡片，一键同步到本机 Anki。
- **保持节奏**：待办清单 + 番茄钟（沉浸专注模式、白噪声）。

这些功能共享同一份本地资料库：导入一次资料，问答、制卡、刷题、导图都能用。

## 使用前需要知道

- AI 能力依赖你自己配置的模型服务（如 DeepSeek、SiliconFlow、OpenAI 等，共 11 家内置
  模板 + 自定义接口），需要自备 API 密钥。配置方法见 [快速上手](start.md)。
- 数据本地优先：资料与聊天记录默认只保存在本机，密钥加密存储。
- 支持 macOS、Windows、Linux、Android，iOS 需自行构建。
