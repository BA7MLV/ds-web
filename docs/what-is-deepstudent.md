# 什么是 DeepStudent

![DeepStudent 学习桌面主界面：AI 对话与思维导图、题目集与 FSRS-6 闪卡多窗口并排协作](/img/guide/study-desktop-hero.webp)

::: tip 一句话介绍
DeepStudent 是开源、本地优先的 AI 学习工作台。它的主角是能直接操作学习桌面各个应用的学习 Agent——说一句话，它就会替你读资料、记笔记、画导图、出题、制卡与安排复习，数据默认保存在你自己的设备上。
:::

## 它能帮你做什么

- **学习桌面与学习 Agent**：应用在[学习桌面](/user-guide/workbench)中以独立窗口并排摆放。学习 Agent 可在分级审批下直接打开应用、写笔记、建导图、出题、制卡与跨轮推进长任务，并能在对话里直接渲染交互式讲解卡片与隔离沙箱演示。
- **围绕资料深度阅读**：导入 PDF、Word、EPUB 与笔记即可提问，回答附带原文页码；内置阅读器支持 AI 论文导读、框选区域提问、PDF 页码跨应用反链与划词联动。
- **音视频陪学**：网课、讲座与录音自动转写为带时间戳的字幕，粘贴 B 站链接即可导入字幕并在应用内播放；支持课中检查点、图文讲义、点击时间戳回跳与页内直接制卡。
- **整理与沉淀知识**：双链 Markdown 笔记、思维导图（导图与大纲双视图，背诵模式一键遮住要点），以及可按学习空间隔离的长期记忆。
- **刷题、闪卡与复习**：AI 识别录题、九种练习模式、持久化试卷与跨题目集错题本；题目集与闪卡统一采用 **FSRS-6** 间隔重复排程，支持对话式 Anki 制卡、同步本机 Anki 或导出 `.apkg`。
- **语言学习与专注节奏**：全文与逐段对照翻译工作台、多场景多轮作文批改，以及待办清单、番茄钟与学习统计中心。
- **技能、MCP 与 AI 插件工坊**：内置 58 个技能，支持接入 MCP 外部工具，并可在[AI 插件工坊](/user-guide/plugin-workshop)里用自然语言制作、安装与热加载 `.dstuplugin` 扩展。

从导入资料到复习复盘，所有应用都由同一个学习 Agent 串联起来：需要整理、出题或制卡时，不必在多个软件之间反复复制粘贴。

## 使用前需要知道

- **自备模型服务**：DeepStudent 本身不内置云端模型，需要接入你自己配置的模型服务。应用预置了 **15 家**模型供应商（DeepSeek、SiliconFlow、OpenAI 等，含 DeepSeek 官方应用能力），也支持自定义接口与本机模型（如 Ollama，免 API 密钥）；首次打开的欢迎弹窗自带「一键 API Key 自动配置」，约 1 分钟即可跑通。详见 [快速上手](start.md)。
- **数据本地优先，但不等于完全离线**：资料、笔记、聊天记录与索引默认保存在本机，密钥加密存储。使用 AI 对话与检索时，所需内容会发送给你配置的模型服务；主动启用联网搜索、MCP 工具或云同步时，也会连接你配置的对应服务。
- **费用说明**：软件免费开源（AGPL-3.0），第三方模型服务商可能按用量收费，具体以所选服务商的计费规则为准。
- **支持平台**：提供 macOS、Windows、Linux 与 Android 客户端，也可在装有 Node.js 24+ 的电脑或服务器上自托管 **WebUI & PWA**，通过浏览器或手机主屏幕访问（见 [WebUI 与 PWA 自托管](/user-guide/webui-pwa)）；iOS 暂无官方安装包，需通过 Xcode 自行构建。
