# 性能实验日志

本日志记录从诊断到最终配对测量的假设、代理指标和保留决定。时间耗时以 `benchmark-final.json` 为最终结论；
中间轮次没有单独的配对 p75 时，不把它们写成独立收益。

## 实验记录

| 轮次 | 假设与最小改动 | 确定性代理指标 | p75 证据 | 决定 |
| --- | --- | --- | --- | --- |
| 0 基线 | 首页把 Mermaid、字体、统计、完整演示和非关键工作一起放在首屏关键路径 | 首页 head 关键资源 31 个、JS 28 个、gzip 1,162,047 B；移动首页可用 4,496.7 ms | 基线冷缓存样本已保存于 `benchmark-final.json` | 继续拆分关键路径 |
| 1 Mermaid 按需 | 首页不需要图表引擎；把 fence 改成轻量 SSR 组件，访问图表页后再动态导入 | 首页图表实现预载 24 → 0；首页保留可读 SSR 回退 | 未单独隔离测量；最终 A/B 作为合并变更证据 | 保留，异步引擎只在使用页面加载 |
| 2 延迟演示与首屏外壳 | 完整 iframe 与首页 CTA 争抢资源；先输出稳定预览，接近视口或主动体验时再启动 | 首屏不创建 iframe；移动请求数 p75 最终 248 → 219；首页可用前阻塞长任务 903 → 470 ms | 合并后的移动首页可用 p75 4,496.7 → 1,583.3 ms；演示真实控件 p75 35,278.3 → 32,091.4 ms | 保留；演示成本单独披露 |
| 3 第三方与非关键工作 | Google Fonts 和同步统计会阻塞；Star、功能图和星空动画可以延后或取消 | 首页 head 外部资源 2 → 0；关键 gzip 1,162,047 → 120,684 B；移动编码字节 p75 4,992,500 → 3,938,906 B | 合并后的移动 LCP p75 2,988 → 1,611 ms | 保留；统计只改变调度，不改变初始化顺序 |
| 4 生产 CSS 扫描 | Tailwind 扫描独立 demo 镜像生成大量不会被站点使用的工具类 | CSS raw 447,325 → 179,116 B；gzip 69,649 → 33,173 B；utilities 260,244 → 4,257 B | 变化与前几轮合并，未把 CSS 差量单独换算成毫秒 | 保留；镜像仍由同步脚本管理 |
| 5 SEO/GEO 与公开表述 | canonical、机器入口和隐私文案必须与实际页面、数据流一致，否则会造成重复抓取或错误承诺 | 24 个 sitemap URL 与可索引页面一致；24 个机器文件；0 审计错误 | 不以 SEO 静态计数冒充性能收益 | 保留；需部署后再查真实 HTTP 路由 |
| 6 最终配对验收 | 同一时段、相同冷缓存和限速下，优化版首页可用 p75 至少降低 50% | 桌面/移动各 10 次，基线与优化共 40/40 次；移动请求、字节、阻塞长任务均下降 | 桌面首页可用 4,705.8 → 1,750.1 ms（62.8%）；移动 4,496.7 → 1,583.3 ms（64.8%） | 目标达到；进入上线前冒烟，不部署 |

## 口径与复核

- 网络：显式下行 1.6 Mbps、上行 750 Kbps、150 ms 延迟；CPU 4 倍降速；文本资源由本地服务 gzip。
- 每次使用新浏览器 context、禁用缓存和 service worker；桌面 1440 × 900，移动 390 × 844。
- 第三方请求在两个版本中都阻断，隔离第一方成本；这不是第三方服务真实成功率或时延的估计。
- 首页可用和演示可用都使用真实 DOM、可见性、启用状态和命中检查；SSR 预览与单独 ready 消息不算演示完成。
- 原始每次采样和汇总见 `perf/bench/benchmark-final.json`；可供 `ratchet.py` 使用的规范化结果见 `perf/bench/ratchet-result.json`。
